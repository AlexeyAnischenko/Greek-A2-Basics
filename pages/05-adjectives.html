05 · Adjectives (Επίθετα)

Rule: the adjective agrees with its noun in gender + case + number, and goes before the noun. ο καλός φίλος · τη μεγάλη πόλη · των ωραίων παιδιών

At A2 you need two and a half patterns: type A, type B, and a handful of type C words.

A · Type -ος / -η / -ο (καλός — good) ← the main one

✦ also: μεγάλος, μικρός, κακός, ακριβός, φτηνός, ψηλός, όμορφος, δύσκολος, εύκολος

B · Type -ος / -α / -ο (ωραίος — nice)

When? Mostly when the stem ends in a vowel — ωραίος, νέος, παλιός, κρύος, άδειος, πλούσιος. ⚠ Compare type A: όμορφος→όμορφη, μικρός→μικρή. Not fully predictable — learn each word with its feminine.

The difference from type A is only the feminine: -α / -ας instead of -η / -ής.

C · Type -ύς / -ιά / -ύ (πλατύς — wide)

Only a few words, but they are common: μακρύς (long), βαθύς (deep), βαρύς (heavy), φαρδύς (wide), ελαφρύς (light). Learn these as a small closed set.
