# B1·09 · Subordinate Clauses (Δευτερεύουσες προτάσεις)

*Ενότητα 8 slot 1, Ενότητα 9 slot 1.*

**A2 had** a list of conjunctions — και, αλλά, όταν, επειδή, αν, που.

**B1 adds** the grammar behind them: clauses come in **two kinds**, and the word that
introduces one tells you which. **Ονοματικές** stand where a noun could stand;
**επιρρηματικές** answer *when, why, where, how*.

Nothing in the A2 area names either kind.

## 1 · Ονοματικές — the relative words

| word | declines? | |
|---|---|---|
| **που** | **no** — one form, always | Οι δάσκαλοι **που** έχουμε φέτος είναι πολύ καλοί. |
| | | Ο δάσκαλος της ζωγραφικής, **που** ήρθε φέτος, είναι πολύ καλός. |
| | | Σήμερα συνάντησα τη δασκάλα **που** ήρθε φέτος. |
| **ό,τι** | **no** — one form | **Ό,τι** μας είπε ο δάσκαλος είναι πολύ σωστό. |
| | | Διάβασα **ό,τι** μας έβαλε ο δάσκαλος. |
| **όσος** | **yes** | **Όσες** ασκήσεις μας έβαλε τις έλυσα. |
| | | **Όσα** μαθήματα είχα για αύριο τα έκανα. |
| | | **Όσες** καθηγήτριες έχει αυτό το σχολείο είναι καλές. |
| **όποιος** | **yes** | **Όποιος** δάσκαλος πάρει αυτή την τάξη θα είναι τυχερός. |
| | | **Όποιοι** μαθητές έγραψαν άσχημα δεν θα πάρουν καλούς βαθμούς. |
| | | **Σε όποια** φροντιστήρια και αν πήγα, δεν βρήκα δάσκαλο σαν αυτόν. |
| | | **Με όποιον** δάσκαλο καθίσεις, τέτοια γράμματα θα μάθεις. |

⚠ **που never changes.** It covers every gender, number and case — *ο δάσκαλος που*,
*τη δασκάλα που*, *οι δάσκαλοι που*. This is why it is the one you reach for by default,
and why it is easy.

⚠ **όσος and όποιος agree with the noun that follows them**, not with anything earlier:
*όσ**ες** ασκήσεις* (feminine plural), *όσ**α** μαθήματα* (neuter plural),
*όποι**ος** δάσκαλος* (masculine singular). And they take prepositions like any
adjective — **σε όποια**, **με όποιον**.

## 2 · ⚠ που / πού and ότι / ό,τι

Four words, two pairs, and the accent or the comma is the whole difference. The course
gives this its own box.

| | | |
|---|---|---|
| **που** | *who, which, that* — joins a clause | Ο κύριος **που** είδαμε χθες… |
| **πού** | *where?* — a question | …με ρώτησε **πού** είναι το πανεπιστήμιο. |
| **ότι** | *that* — introduces a statement | Ξέρεις **ότι** πεινάω πάρα πολύ; |
| **ό,τι** | *whatever, anything that* | Μπορώ να φάω **ό,τι** να 'ναι. |

> Ο καθηγητής **που** μας κάνει γυμναστική με ρώτησε **πού** είναι οι φόρμες μου.
> Ο Νίκος μου είπε **ότι** πρέπει να προσέξω! **Ό,τι** λάμπει δεν είναι χρυσός.
> Της απάντησα **ότι**, **ό,τι** κι αν πει, εγώ θα πάω.

**The comma in ό,τι is not optional** — it is what separates *whatever* from *that*. The
last example has both words in one sentence, two words apart.

## 3 · Επιρρηματικές — by what they answer

| answers | word | |
|---|---|---|
| **χρόνο** — when | **μόλις** | **Μόλις φθάσαμε στη Νάπη**, καθίσαμε λίγο στο χωριό. |
| | **ενώ** | **Ενώ συζητούσαμε και πίναμε τον καφέ μας**, ήρθε ο Στέλιος. |
| | **καθώς** | **Καθώς ερχόμουν**, είδα τα σημάδια της φύσης. |
| **αιτία** — why | **επειδή** | Πλησιάζει καταιγίδα, **επειδή σμήνη πουλιών πετάνε χαμηλά**. |
| | **που** | Ήμουν πολύ χαρούμενος **που ήμασταν εκεί**. |
| **αντίθεση** — although | **αν και** | Πολλοί, **αν και δεν έχουν μετεωρολογικά όργανα**, προβλέπουν τον καιρό. |
| | **ενώ** | **Ενώ δεν έχουν σπουδάσει**, είναι πολύ καλοί μετεωρολόγοι. |
| **τόπο** — where | **όπου** | **Όπου βρίσκονται**, μπορούν να καταλάβουν τι καιρό θα κάνει. |
| **τρόπο** — how | **όπως** | Ερμηνεύουν **όπως θέλουν** τα φυσικά σημάδια. |

⚠ **ενώ does two jobs.** *Ενώ συζητούσαμε* is **time** — while we were talking. *Ενώ δεν
έχουν σπουδάσει* is **contrast** — although they never studied. Only the sense tells them
apart, and the same sentence pattern carries both.

⚠ **που is also a cause.** *Ήμουν χαρούμενος **που** ήμασταν εκεί* — "I was glad **that**
we were there", not "which". So που has three jobs: relative, cause, and (as πού) a
question word.
