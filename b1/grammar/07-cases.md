# B1·07 · Using the Cases (Χρήση των πτώσεων) — genitive & accusative

*Ενότητα 6 — Γραμματική, slot 1.*

**A2 had** what each case *is* and which question word asks for it.

**B1 adds** the part that decides real sentences: **when two nouns meet, which case does the
second one take** — and the answer turns out to change the meaning, not just the form.

## 1 · Γενική — the default for noun + noun

| | |
|---|---|
| whose | Οι μαμάδες **των μικρών παιδιών** έχουν πολύ πλύσιμο. |
| | Προσέξτε τα ρούχα **των παιδιών** στο πλύσιμο. |
| what kind, what for | Πλύνετε τα ρούχα **της δουλειάς** σε υψηλές θερμοκρασίες. |
| | Τα ρούχα **καλής ποιότητας** δεν χαλάνε. |
| which one's | Τα ρούχα αυτού **του σχεδιαστή** είναι μοντέρνα. |
| of what season / source | Προσέξτε τον ήλιο **του καλοκαιριού**. |
| | Έπλεναν τα ρούχα με το νερό **της βροχής**. |
| | Δείτε τις ετικέτες **των ρούχων**. |
| where it is | Έκλεισε το καθαριστήριο **της πλατείας** Σκρα. |
| **to whom** ⚠ | Έδωσα **του Γιάννη** ένα βιβλίο. |

⚠ **The genitive is also the indirect object.** *Έδωσα **του Γιάννη** ένα βιβλίο* —
"I gave John a book". A2 teaches *σε + accusative* for this (*έδωσα στον Γιάννη*); both are
right, and the bare genitive is the one you will meet in writing.

## 2 · Αιτιατική — measure and time

| | |
|---|---|
| how much | Αγοράστε ύφασμα δύο **μέτρα**. |
| how often | Σιδερώστε δύο φορές **την εβδομάδα**. |
| | Σιδερώστε τα ρούχα σας μία φορά **την εβδομάδα**. |
| when | **Το Σάββατο το βράδυ** είναι καλή ώρα να σιδερώσετε. |
| | **Τον χειμώνα** χρησιμοποιήστε το στεγνωτήριο. |
| how old | τα ρούχα κάποιου παιδιού που είναι **δύο χρονών** |

⚠ **Time is accusative, not genitive.** *τον χειμώνα*, *το Σάββατο το βράδυ*,
*την εβδομάδα*. The course's own question makes the split explicit: the second noun goes
genitive **τις περισσότερες φορές**, but accusative **όταν αναφέρεται στον χρόνο**.

### The question words

| question | case |
|---|---|
| **τίνος;** | γενική |
| **τι; ποιον;** | αιτιατική |
| **πότε;** | **αιτιατική** |

## 3 · ⚠ The pair that changes meaning

This is the heart of the lesson. Same two nouns, different case, different thing.

| ΓΕΝΙΚΗ — what it is *for* | ΑΙΤΙΑΤΙΚΗ — what is *in* it |
|---|---|
| Πού είναι τα **ποτήρια κρασιού**; <br>*the wine glasses* | Ένα **ποτήρι κρασί**, παρακαλώ. <br>*a glass of wine* |
| Βάζω ένα **κουταλάκι του γλυκού** ζάχαρη. <br>*a teaspoon (the implement)* | Μου δίνεις ένα **κουταλάκι γλυκό**; <br>*a spoonful of dessert* |
| Πόσα **πιάτα σούπας** να φέρω; <br>*soup plates* | Έφαγα ένα **πιάτο σούπα**. <br>*a plate of soup* |

**Genitive describes the vessel. Accusative measures the contents.** Ask for *ένα ποτήρι
κρασιού* in a taverna and you have asked for the glassware.

## 4 · Prepositions by case

| + ΓΕΝΙΚΗ | + ΑΙΤΙΑΤΙΚΗ |
|---|---|
| **εξαιτίας** | **με · για · από · σε · ως · μετά · χωρίς / δίχως** |

⚠ **Almost every preposition takes the accusative.** The course lists exactly one that
takes the genitive — **εξαιτίας** (*because of*). That is the whole exception, so learn the
one rather than the many.

## 5 · Set expressions, by case

| ΓΕΝΙΚΗ | ΑΙΤΙΑΤΙΚΗ |
|---|---|
| Ρούχα **της μόδας**. — fashionable clothes | **Σε** πήρα τηλέφωνο. — I phoned you |
| Πεθαίνω **της πείνας**. — I'm starving | Λείπει **(σε) ταξίδι**. — he's away travelling |
| Θα φύγω **του χρόνου**. — I'll leave next year | **Τον** πήρε αγκαλιά. — she hugged him |
| **Και του χρόνου!** — same again next year! | Βγήκα **βόλτα**. — I went out for a walk |
| **Μπράβο σου!** — well done! | Πήγα **επίσκεψη** στην Ελένη. — I visited Eleni |
| **Περαστικά σου!** — get well soon! | **Τον καημένο!** — poor thing! |

⚠ **Μπράβο σου** and **Περαστικά σου** are genitives — the σου is the weak genitive, the
same one as in *το σπίτι σου*. They are frozen; nothing else in them changes.

⚠ **Τον καημένο!** is an accusative with no verb at all — an exclamation standing alone.
