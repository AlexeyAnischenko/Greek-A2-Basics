# B1·02 · Άρθρο & αριθμοί

*KLIK B1, Ενότητα 2 — Γραμματική σ. 68 (αριθμοί) and σσ. 70–71 (άρθρο).*

**A2 had** the article's **forms** — ο/η/το, του/της/του, τον/την/το, and ένας/μία/ένα —
and numbers as far as χίλια.

**B1 adds** the part that is actually hard: **when to use which one, and when to use none
at all**. The book gives it as one long three-column table, αόριστο / οριστικό / χωρίς
άρθρο, running over two pages. Nothing in the A2 area covers this.

## 1 · Definite, indefinite, or nothing (σσ. 70–71)

### Nouns

| | αόριστο | οριστικό | χωρίς άρθρο |
|---|---|---|---|
| **first mention → later mention** | Έκανα **ένα ταξίδι** και πέρασα ωραία. | …κι ένα στην Ελβετία. **Το ταξίδι** στην Ιαπωνία δεν θα το ξεχάσω. | |
| **one of many → the known one** | Ήρθε **ένας κύριος**. | Ήρθε **ο κύριος** με τα γυαλιά. | Δεν ήρθε **κανένας κύριος**. |
| | Ήρθε **ένας θείος** της. | Ήρθε **ο θείος** της. | |
| **a window / the window** | Ανοίγεις **ένα παράθυρο**; | Ανοίγεις **το παράθυρο**; | |
| **what he's wearing** | Φοράει **ένα μπλε πουκάμισο**. | Φοράει **το μπλε πουκάμισο**. | Φοράει **μπλε πουκάμισο**. |
| **means of transport** | | Ταξιδεύω **με το τρένο**. | Ταξιδεύω **με τρένο**. |

⚠ **Greek puts the definite article where English drops it** — on whole classes, on
abstractions, on unique things, on place names:

> Αγαπώ **τα σκυλιά**. · **Ο χορός** μού αρέσει πάρα πολύ. · Είδες **το φεγγάρι**; ·
> Μου αρέσει **η Αθήνα**. · **Η ζωή** είναι ωραία.

⚠ **And leaves it out where English might keep it** — calling someone, naming, describing,
and after είμαι / γίνομαι with a profession:

> Γεια σου, **Πέτρο**. · Τον λένε **Πέτρο**. · Έχει **σγουρά μαλλιά**. ·
> Πίνει **ούζο** και τρώει **ψάρια**. · Είναι **φοιτητής**. · Θα γίνει **αρχιτέκτονας**.

### Pronouns

| | οριστικό | χωρίς άρθρο |
|---|---|---|
| demonstrative | **Αυτή / Εκείνη η φίλη** μου… · **Όλες οι φίλες** μου… | |
| **ο ίδιος** vs **ίδιος** | Ήρθε **ο ίδιος** — *the man himself* | Είναι **ίδιος** με τη μητέρα του — *just like* |
| **ο μόνος** vs **μόνος** | Είναι **ο μόνος** που με πληρώνει — *the only one* | Έμεινε **μόνος** του — *alone* |
| ο ένας … ο άλλος | Έχω δύο γιους. **Ο ένας** … και **ο άλλος** … | |

⚠ **ο ίδιος / ο μόνος with the article mean something different from ίδιος / μόνος
without it.** That pair is half of the Οριστικές αντωνυμίες slot in the contents.

Question words and indefinites take **no** article:

> **Τι ψωμί** θέλετε; · Έχει **τίποτα φρούτα**; · **Πόσα φρούτα** έχει; · Έχει **τόσα φρούτα**! ·
> **Όσα φρούτα** και να φάω… · **Όποιος μαθητής** διαβάζει… · **Ποιος κύριος** ήρθε; ·
> Ήρθαν **κάτι / μερικοί / κάποιοι** κύριοι.

### Time (σ. 71)

| αόριστο — *one particular one* | οριστικό — *the one coming* | χωρίς άρθρο — *bare* |
|---|---|---|
| Γεννήθηκε **ένα μεσημέρι** | Θα τα πούμε **το μεσημέρι** | Γεννήθηκε **μεσημέρι** |
| **έναν Οκτώβρη** | **τον Οκτώβρη** | **Οκτώβρη** |
| **μια Κυριακή** | **την Κυριακή** | **Κυριακή** |
| **ένα καλοκαίρι** | **το καλοκαίρι** | **καλοκαίρι** |
| | **στις 12** το βράδυ · **στις 27** Ιουνίου | **27 Ιουνίου** |
| | **την Πρωτοχρονιά** · **το 2013** | |

### Quantity (σ. 71)

| οριστικό | χωρίς άρθρο |
|---|---|
| Πόσο **τα μήλα**; — Δύο ευρώ **το κιλό**. | Τρία **κιλά μήλα**. |
| Πόσα βιβλία διαβάζεις **τον χρόνο**; | Ένα **ποτήρι νερό**. · Θέλω **νερό**. |
| 800 ευρώ **το τετραγωνικό μέτρο** · 30 ευρώ **την ώρα** | Ήρθαν **δύο άτομα**. |
| Ήρθαν **και οι δύο**. | |
| Περπατάει **σαν τη χελώνα** / **όπως η χελώνα**. | Περπατάει **σαν χελώνα**. |

⚠ **"per" is the definite article** — *δύο ευρώ **το** κιλό*, *30 ευρώ **την** ώρα*,
*πόσα βιβλία **τον** χρόνο*. English uses *a* or *per*; Greek uses *the*.

Also bare: Έχω **δίπλωμα**, αλλά δεν έχω **αυτοκίνητο**. · Οδηγείς **μηχανάκι**; ·
Αν τρως **φρούτα**, θα αδυνατίσεις.

### Fixed expressions (σ. 71)

**No article** is the normal form:

> έχω **διάθεση** / **όρεξη** / **λεφτά** / **πονοκέφαλο** / **δίκιο** / **άδικο** /
> **εμπιστοσύνη** / **σκοπό να**… · έχει **ήλιο** / **λιακάδα** / **σύννεφα** / **φασαρία**
> κάνει **ζέστη** / **κρύο** · κάνω **φασαρία** / **μπάνιο** / **φαγητό** ·
> ακούω **μουσική** · διαβάζω **εφημερίδες** · περιμένω **παιδί** · βλέπω **τηλεόραση** ·
> παίζω **ποδόσφαιρο**

With a preposition: χωρίς **όρεξη**, με **ήλιο**, από **άγχος**, από **οικογένεια**,
από **ξύλο**, από **ύφασμα**, σαν **λύκος**, με **αγάπη**, με **χαρά**

Compound terms: δελτίο **ταυτότητας**, άδεια **οδήγησης**, έξοδος **κινδύνου**,
λύση **ανάγκης**, ώρες **γραφείου**, ποιότητα **ζωής**, διεύθυνση **κατοικίας**,
τόπος **διαμονής**

Addresses: οδός **Αριστοτέλους**, πλατεία **Ναβαρίνου**, Δήμος **Δράμας**,
Αριστοτέλειο **Πανεπιστήμιο Θεσσαλονίκης**

Shouts: **Βοήθεια!** **Προσοχή!**

⚠ **The indefinite turns these emphatic.** *Έχω όρεξη* is "I'm hungry";
*Έχω **μια** όρεξη…!* is "I am **so** hungry". Same for *έχω **έναν** πονοκέφαλο…*,
*κάνει **μια** ζέστη…*, *έχει **μια** φασαρία…*. Also the story opener
**Μια φορά κι έναν καιρό**…

## 2 · The thousands (σ. 68)

**χίλιοι declines by gender** — and above it you switch to a feminine noun.

| | |
|---|---|
| **1.000** | **χίλιοι** / **χίλιες** / **χίλια** |
| 1.001 | χίλιοι ένας · χίλιες μία · χίλια ένα |
| 1.002 | χίλιοι / χίλιες / χίλια **δύο** |
| 1.003 | χίλιοι / χίλιες **τρεις** · χίλια **τρία** |
| 1.004 | χίλιοι / χίλιες **τέσσερις** · χίλια **τέσσερα** |
| 1.005 | χίλιοι / χίλιες / χίλια **πέντε** |

| | |
|---|---|
| **2.000** | **δύο χιλιάδες** |
| 3.000 | **τρεις** χιλιάδες |
| 4.000 | **τέσσερις** χιλιάδες |
| 5.000 | πέντε χιλιάδες |
| 100.000 | **εκατό** χιλιάδες |
| 200.000 | **διακόσιες** χιλιάδες |

⚠ **η χιλιάδα is a feminine noun**, so whatever multiplies it goes feminine:
**τέσσερις** χιλιάδες (not τέσσερα), **διακόσιες** χιλιάδες (not διακόσια).
This is the trap — you count *things* with τέσσερα and *thousands* with τέσσερις.
