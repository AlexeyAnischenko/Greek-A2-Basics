# B1·01 · Ισοσύλλαβα & ανισοσύλλαβα ουσιαστικά

*Ενότητα 1 — Γραμματική, both slots.*

**A2 had** the noun declensions one by one — M1 -ας, M2 -ης, F1 -α, N1 -ο and the rest,
with the plural of each.

**B1 adds** the word for the split — a noun is **ισοσύλλαβο** if it keeps its syllable
count through the cases and **ανισοσύλλαβο** if it gains one — and then the part A2 left
out: the **genitive plural**, which is where the stress moves.

## 1 · The rule in one line

| | singular | plural | |
|---|---|---|---|
| **Ισοσύλλαβο** | ο χα-ρα-κτή-ρας (4) | οι χα-ρα-κτή-ρες (4) | same count |
| **Ανισοσύλλαβο** | ο ψα-ράς (2) | οι ψα-ρά-δες (3) | **one more** |

The ανισοσύλλαβα gain **-δ-** (ψαρά**δ**ες) or, in the neuter, **-τ-** (γεύμα**τ**α).

## 2 · Ισοσύλλαβα — masculine

| -ας | ο χαρακτήρας | ο άντρας | ο παράγοντας |
|---|---|---|---|
| του | χαρακτήρα | άντρα | παράγοντα |
| οι | χαρακτήρες | άντρες | παράγοντες |
| **των** | χαρακτήρων | **αντρών** ← | **παραγόντων** ← |

| -ής / -ης | ο διευθυντής | ο συγγενής | ο ναύτης |
|---|---|---|---|
| του | διευθυντή | συγγενή | ναύτη |
| οι | διευθυντές | **συγγενείς** ⚠ | ναύτες |
| **των** | διευθυντών | συγγενών | **ναυτών** ← |

| -ός / -ος | ο γιατρός | ο δικηγόρος | ο άνθρωπος |
|---|---|---|---|
| του | γιατρού | δικηγόρου | **ανθρώπου** ← |
| τον | γιατρό | δικηγόρο | άνθρωπο |
| **κλητική** | γιατρέ | δικηγόρε | άνθρωπε |
| οι | γιατροί | δικηγόροι | άνθρωποι |
| **των** | γιατρών | δικηγόρων | **ανθρώπων** ← |
| τους | γιατρούς | δικηγόρους | **ανθρώπους** ← |

⚠ **ο συγγενής → οι συγγενείς**, not *συγγενήδες and not *συγγενές. It is the one
masculine in the table with a learned plural.

## 3 · Ισοσύλλαβα — feminine

| -α / -ά | η καρδιά | η γυναίκα | η εικόνα | η οικογένεια | η ικανότητα |
|---|---|---|---|---|---|
| της | καρδιάς | γυναίκας | εικόνας | οικογένειας | ικανότητας |
| οι | καρδιές | γυναίκες | εικόνες | οικογένειες | ικανότητες |
| **των** | καρδιών | **γυναικών** ← | εικόνων | **οικογενειών** ← | **ικανοτήτων** ← |

| -η / -ή | η ψυχή | η γνώμη | η εξέταση | η σκέψη |
|---|---|---|---|---|
| της | ψυχής | γνώμης | εξέτασης | σκέψης |
| οι | ψυχές | γνώμες | **εξετάσεις** ⚠ | **σκέψεις** ⚠ |
| **των** | ψυχών | **γνωμών** ← | **εξετάσεων** ⚠ | **σκέψεων** ⚠ |

**Feminine -ος** — declines like the masculine but takes feminine articles:
η μέθοδος · της μεθόδου · τη(ν) μέθοδο · οι μέθοδοι · των μεθόδων · τις μεθόδους

⚠ **-ση / -ξη / -ψη → -σεις / -ξεις / -ψεις**, genitive plural **-σεων / -ξεων / -ψεων**.
This is the F3 type from A2 page 4, now with its genitive plural filled in.

## 4 · Ισοσύλλαβα — neuter

| -ό / -ο | το μυστικό | το άρθρο | το πρόσωπο | το χαμόγελο |
|---|---|---|---|---|
| του | μυστικού | άρθρου | **προσώπου** ← | χαμόγελου |
| τα | μυστικά | άρθρα | πρόσωπα | χαμόγελα |
| **των** | μυστικών | άρθρων | **προσώπων** ← | χαμόγελων |

| -ί / -ι | το μαλλί | το φρύδι | | -ος | το βάρος |
|---|---|---|---|---|---|
| του | μαλλιού | **φρυδιού** ← | | του | βάρους |
| τα | μαλλιά | φρύδια | | τα | **βάρη** ⚠ |
| **των** | μαλλιών | **φρυδιών** ← | | **των** | **βαρών** ← |

## 5 · Ανισοσύλλαβα — masculine

| | ονομαστική | γενική | αιτιατική |
|---|---|---|---|
| **-άς → -άδες** | ο ψα-**ράς** | του ψα-**ρά** | τον ψα-**ρά** |
| | οι ψα-ρά-**δες** | των ψα-ρά-**δων** | τους ψα-ρά-**δες** |
| **-ής → -ήδες** | ο κου-λουρ-**τζής** | του κου-λουρ-**τζή** | τον κου-λουρ-**τζή** |
| | οι κου-λουρ-τζή-**δες** | των κου-λουρ-τζή-**δων** | τους κου-λουρ-τζή-**δες** |
| **-ης → -ηδες** | ο μα-**νά**-βης | του μα-**νά**-βη | τον μα-**νά**-βη |
| | οι μα-νά-βη-**δες** | των μα-νά-βη-**δων** | τους μα-νά-βη-**δες** |
| **-ές → -έδες** | ο κα-**φές** | του κα-**φέ** | τον κα-**φέ** |
| | οι κα-φέ-**δες** | των κα-φέ-**δων** | τους κα-φέ-**δες** |
| **-ούς → -ούδες** | ο παπ-**πούς** | του παπ-**πού** | τον παπ-**πού** |
| | οι παπ-πού-**δες** | των παπ-πού-**δων** | τους παπ-πού-**δες** |

✦ **-άς** ντολμάς, βασιλιάς, μπαμπάς, λουκουμάς
✦ **-ής / -ης** μπογιατζής, ταξιτζής, χιμπατζής, παγωτατζής · μπέμπης, νοικοκύρης, τσαγκάρης, χασάπης
✦ **-ές** καναπές, μεζές, λεκές, τενεκές

⚠ **ο νους** — μόνο στον ενικό. No plural at all.

✦ The **-ηδες** plural is the one the adjective type **-ης / -α / -ικο** borrows:
ο μανάβης → οι μανάβηδες, so ζηλιάρης → οι ζηλιάρηδες (A2 page 7).

## 6 · Ανισοσύλλαβα — feminine

| | ονομαστική | γενική | αιτιατική |
|---|---|---|---|
| **-ά → -άδες** | η για-**γιά** | της για-**γιάς** | τη για-**γιά** |
| | οι για-γιά-**δες** | των για-γιά-**δων** | τις για-γιά-**δες** |
| **-ού → -ούδες** | η α-λε-**πού** | της α-λε-**πούς** | την α-λε-**πού** |
| | οι α-λε-πού-**δες** | των α-λε-πού-**δων** | τις α-λε-πού-**δες** |

✦ **-ά** μαμά, νταντά ✦ **-ού** μαϊμού

⚠ **της αλεπούς** — the genitive singular keeps the **-ς**. η γιαγιά does too (της γιαγιάς),
but the -ού type is the one that looks wrong and is right.

## 7 · ⚠ The final -ν, printed as a rule

The book makes this a boxed Προσοχή next to τη γιαγιά / την αλεπού:

| | the article | before |
|---|---|---|
| **τη** γιαγιά | drops the -ν | β, γ, δ, ζ, θ, λ, μ, ν, ρ, σ, φ, χ |
| **την** αλεπού | keeps the -ν | κ, π, τ, μπ, ντ, γκ, τζ, τσ, ψ, ξ **or a vowel** |

## 8 · Ανισοσύλλαβα — neuter

| | ονομαστική | γενική | αιτιατική |
|---|---|---|---|
| **-μα → -ματα** | το μα-γεί-ρε-**μα** | του μα-γει-ρέ-**μα-τος** | το μα-γεί-ρε-**μα** |
| | τα μα-γει-ρέ-**μα-τα** | **των μα-γει-ρε-μά-των** ← | τα μα-γει-ρέ-**μα-τα** |
| | το **γεύ**-μα | του **γεύ**-μα-τος | το **γεύ**-μα |
| | τα **γεύ**-μα-τα | **των γευ-μά-των** ← | τα **γεύ**-μα-τα |
| **-ας → -ατα** | το **κρέ**-ας | του **κρέ**-α-τος | το **κρέ**-ας |
| | τα **κρέ**-α-τα | **των κρε-ά-των** ← | τα **κρέ**-α-τα |
| **γάλα** | το **γά**-λα | του **γά**-λα-(κ)τος | το **γά**-λα |
| | τα **γά**-λα-τα | — ⚠ | τα **γά**-λα-τα |

✦ **-μα** άρωμα, κάθισμα, διάβασμα, όνομα, γράμμα, κέρμα, χρήμα, χρώμα ✦ **-ας** τέρας

⚠ **γάλα has no genitive plural.** And its genitive singular keeps an optional learned
**-κτ-**: του γάλα**κτος**.

## 9 · Three lists A2 never gave you

### Ουσιαστικά χωρίς πληθυντικό — no plural

θράσος · τόλμη · ειρήνη · δύση · γη · θέα · αφή · τάβλι · γαλήνη · ηρεμία

### Ουσιαστικά χωρίς ενικό — no singular

εγκαίνια · (μιλώ) ελληνικά / σουηδικά / γαλλικά · διόδια · μεσάνυχτα · μαθηματικά · γενέθλια

⚠ The languages are **plural**: *μιλώ ελληνικά*, never *μιλώ ελληνικό*.

### Ουσιαστικά με διαφορετική σημασία στον ενικό και στον πληθυντικό

| singular | plural |
|---|---|
| **η διακοπή** — a cut, an interruption | **οι διακοπές** — a holiday |
| *Χθες είχαμε διακοπή νερού.* | *Αύριο ξεκινούν οι διακοπές μου.* |
| **η έκπτωση** — a discount | **οι εκπτώσεις** — the sales |
| *Αγόρασα αυτό το φόρεμα με έκπτωση.* | *Αγόρασα αυτό το φόρεμα στις εκπτώσεις.* |
