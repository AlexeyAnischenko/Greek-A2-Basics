# B1·08 · Pronouns (Αντωνυμίες) — definite, demonstrative, indefinite

*Ενότητα 2 slot 2, Ενότητα 6 slot 2.*

**A2 had** the personal pronouns (strong and weak), the possessives, and αυτός / εκείνος.

**B1 adds** three families A2 never names: the **οριστικές** (ο ίδιος, μόνος), the
**δεικτικές** of quality and quantity (τέτοιος, τόσος), and the **αόριστες**
(κάποιος, άλλος, αρκετός, καθένας).

## 1 · μόνος — three different words

| | means | |
|---|---|---|
| **μόνος μου** | by myself, unaccompanied | Εγώ πήγα **μόνος μου** στη γιορτή. |
| **ο μόνος** | the only one | Εγώ είμαι **ο μόνος** που πήγε στη γιορτή. |
| | | Αυτή είναι **η μόνη** τράπεζα στη γειτονιά. |
| **μόνο** | only *(adverb, never changes)* | Κάνω δίαιτα, τρώω **μόνο** λαχανικά. |

### μόνος takes a possessive that agrees with the subject

| | |
|---|---|
| Εγώ πήγα | μόνος / μόνη / μόνο **μου** |
| Εσύ πήγες | μόνος / μόνη / μόνο **σου** |
| Αυτός / Αυτή / Αυτό πήγε | μόνος **του** / μόνη **της** / μόνο **του** |
| Εμείς πήγαμε | μόνοι / μόνες / μόνα **μας** |
| Εσείς πήγατε | μόνοι / μόνες / μόνα **σας** |
| Αυτοί / Αυτές / Αυτά πήγαν | μόνοι / μόνες / μόνα **τους** |

⚠ **Two things agree at once** — the adjective with the subject's gender and number, the
possessive with its person. *Οι γυναίκες πήγαν **μόνες τους***, never *μόνοι τους*.

## 2 · ο ίδιος — four senses

| | means | |
|---|---|---|
| answering the phone | *speaking* | «Την κ. Μακρή, παρακαλώ.» — «**Η ίδια**.» |
| **τα ίδια** + noun | the same | Η Ελένη και εγώ φοράμε **τα ίδια ρούχα**. |
| **ο ίδιος ο** + noun | emphasis on the person | Μίλησα με **τους ίδιους τους γιατρούς** / με **τους γιατρούς τους ίδιους**. |
| **το ίδιο** + adjective | as … as | Ο Νίκος είναι **το ίδιο ψηλός** με τον Λευτέρη. |

### The full set

| | |
|---|---|
| Εγώ · Εσύ · Αυτός/ή/ό | **ο ίδιος / η ίδια / το ίδιο** |
| Εμείς · Εσείς · Αυτοί/ές/ά | **οι ίδιοι / οι ίδιες / τα ίδια** |

⚠ Unlike μόνος, ο ίδιος takes **no possessive** — just the article. *Εγώ **ο ίδιος***, not
*ο ίδιος μου*.

⚠ **The article changes the meaning.** *Είναι **ο ίδιος*** = he's the same man;
*Είναι **ίδιος** με τη μητέρα του* = he's the image of his mother. Same for
*ο μόνος* (the only one) against *μόνος του* (on his own). Sheet 02 has this from the
article's side.

## 3 · τέτοιος & τόσος

| | asks about | |
|---|---|---|
| **τέτοιος** | **ποιότητα** — what kind | Τι ωραία τσάντα! Θέλω μια **τέτοια** κι εγώ. |
| | | Θέλω μια **τέτοια τσάντα** κι εγώ. |
| | | Με **τέτοιο θόρυβο** δεν μπορώ να δουλέψω. |
| **τόσος** | **ποσότητα, μέγεθος, ένταση** | «Να βάλω κι άλλη ζάχαρη;» — «Όχι, φτάνει **τόση**.» |
| | | Δεν θέλω **τόση ζάχαρη** στον καφέ μου. |
| | | Με **τόσο θόρυβο** δεν μπορώ να δουλέψω. |
| | intensifying an adjective or adverb | Δεν περίμενα να είναι **τόσο καλός**. |
| | | Δεν περίμενα να περάσω **τόσο καλά**. Πέρασα **τόσο ωραία**! |

⚠ **Με τέτοιο θόρυβο** and **με τόσο θόρυβο** are both good Greek and mean different
things — *with noise like that* against *with that much noise*.

⚠ Both can stand alone without a noun: *θέλω μια **τέτοια***, *φτάνει **τόση***.

## 4 · Αόριστες αντωνυμίες

| Ενικός | Πληθυντικός |
|---|---|
| **κάποιος, κάποια, κάποιο** — someone, some | κάποιοι, κάποιες, κάποια |
| **άλλος, άλλη, άλλο** — other, another | άλλοι, άλλες, άλλα |
| **αρκετός, αρκετή, αρκετό** — enough, quite a few | αρκετοί, αρκετές, αρκετά |
| **καθένας, καθεμιά (καθεμία), καθένα** — each one | **—** ⚠ |

⚠ **καθένας has no plural**, and the course leaves the cell empty. It is singular by
definition — *ο καθένας έχει τη γνώμη του*.

⚠ All four decline like ordinary type-A or type-B adjectives. κάποιος and άλλος follow
**-ος / -α / -ο** (κάποια, άλλη — watch that άλλος takes **-η**, κάποιος takes **-α**).

### ⚠ μια άλλη vs άλλη μια — the word order carries the meaning

The course prints these two side by side and says nothing. The difference is real:

| | |
|---|---|
| Αυτή η σακούλα είναι **σκισμένη**. Δώστε μου **μια άλλη** σακούλα. | *a **different** bag* — this one is torn |
| Αυτή η σακούλα **γέμισε**. Δώστε μου **άλλη μια** σακούλα. | *one **more** bag* — this one is full |

**μια άλλη** = a different one, replacing this. **άλλη μια** = another one, in addition.
Swap the two words and you have asked for the wrong thing.
