# B1·11 · Conditionals (Υποθετικοί λόγοι)

*Ενότητα 9 — Γραμματική, slot 2.*

**A2 had** *αν* in the conjunction list and nothing about what follows it.

**B1 adds** the split the whole system turns on: a conditional is either about
**το πραγματικό** — something that can happen or did — or **το μη πραγματικό** —
something that cannot or did not. The tenses you use are completely different.

## 1 · The two groups

| | **Α · Το πραγματικό** | **Β · Το μη πραγματικό** |
|---|---|---|
| means | it is possible, or it happened | it is not possible, or it did not happen |
| the **αν** clause | present or past **indicative** | **παρατατικό** or **υπερσυντέλικο** |
| the result | future, present, or **imperative** | **θα + παρατατικός** or **θα + υπερσυντέλικος** |

## 2 · Α · Το πραγματικό

| Αν… | …τότε |
|---|---|
| **Αν** το αυτοκίνητό σας **είναι** σε καλή κατάσταση, | **θα καίει** λιγότερα καύσιμα. |
| | **θα ρυπαίνει** λιγότερο την ατμόσφαιρα. |
| **Αν οδηγείτε** νευρικά, | **καταναλώνετε** περισσότερα καύσιμα. |
| **Αν έχει** μποτιλιάρισμα περισσότερο από 3 λεπτά, | **σβήστε** τη μηχανή. |
| **Αν χρειάζεστε** καινούρια λάδια, | **να δώσετε** τα παλιά σε ένα συνεργείο. |
| **Αν** τα λάστιχα **χάλασαν**, | θα πρέπει **να τα αλλάξετε**. |

⚠ **The result half is free.** It can be a future (*θα καίει*), a plain present
(*καταναλώνετε*), an **imperative** (*σβήστε*), or a **να-form** (*να δώσετε*). Greek does
not force one shape — this is advice, and advice ends in whatever fits.

⚠ **Αν never takes θα.** The condition is *αν **είναι***, *αν **οδηγείτε***,
*αν **χάλασαν*** — never *αν θα είναι*. Only the result half gets θα.

## 3 · Β · Το μη πραγματικό

| Αν… | …τότε |
|---|---|
| **Αν** δεν **οδηγούσαμε** με λάθος τρόπο, | δεν **ήταν** τόσο μολυσμένη η ατμόσφαιρα. |
| | **θα εξοικονομούσαμε** καύσιμα, αλλά και χρήματα. |
| **Αν είχαμε αλλάξει** εδώ και χρόνια την οδήγησή μας, | **θα είχαμε βοηθήσει** το περιβάλλον, αλλά και την τσέπη μας. |

| | the pattern |
|---|---|
| **present unreal** — *if we weren't… we wouldn't be…* | αν + **παρατατικός** → **θα** + **παρατατικός** |
| **past unreal** — *if we had… we would have…* | αν + **υπερσυντέλικος** → **θα** + **υπερσυντέλικος** |

⚠ **The imperfect is doing a job it does not look like it is doing.** *Αν δεν οδηγούσαμε*
is not about the past — it means *if we didn't drive*, right now. The παρατατικός is how
Greek marks the unreal, not only the ongoing-past (sheet 06).

⚠ **θα + παρατατικός is the "would" of Greek.** *θα εξοικονομούσαμε* = we **would** save.
There is no separate conditional tense to learn; it is θα on a tense you already have.

✦ And **θα + υπερσυντέλικος** = *would have*. Which makes the έχω system complete across
all four uses — έχω βοηθήσει, είχα βοηθήσει, θα έχω βοηθήσει, θα είχα βοηθήσει.

## 4 · The two side by side

| | real | unreal |
|---|---|---|
| present | **Αν οδηγείτε** νευρικά, καταναλώνετε περισσότερα καύσιμα. | **Αν δεν οδηγούσαμε** έτσι, **θα εξοικονομούσαμε** καύσιμα. |
| past | **Αν** τα λάστιχα **χάλασαν**, θα πρέπει να τα αλλάξετε. | **Αν είχαμε αλλάξει** την οδήγησή μας, **θα είχαμε βοηθήσει** το περιβάλλον. |

The course's own check questions are exactly this: *which group expresses what is possible
or did happen, and which expresses what is not possible or did not happen?*

## 5 · Drill

| Say in Greek | Answer |
|---|---|
| If your car is in good condition, it will burn less fuel | Αν το αυτοκίνητό σας είναι σε καλή κατάσταση, θα καίει λιγότερα καύσιμα |
| If you drive nervously, you use more fuel | Αν οδηγείτε νευρικά, καταναλώνετε περισσότερα καύσιμα |
| If there's a jam for more than 3 minutes, switch the engine off | Αν έχει μποτιλιάρισμα περισσότερο από 3 λεπτά, σβήστε τη μηχανή |
| If you need new oil, give the old to a garage | Αν χρειάζεστε καινούρια λάδια, να δώσετε τα παλιά σε ένα συνεργείο |
| If we didn't drive badly, we would save fuel | Αν δεν οδηγούσαμε με λάθος τρόπο, θα εξοικονομούσαμε καύσιμα |
| …the air wouldn't be so polluted | …δεν ήταν τόσο μολυσμένη η ατμόσφαιρα |
| If we had changed, we would have helped the environment | Αν είχαμε αλλάξει, θα είχαμε βοηθήσει το περιβάλλον |
| we would save | θα εξοικονομούσαμε |
| we would have helped | θα είχαμε βοηθήσει |
