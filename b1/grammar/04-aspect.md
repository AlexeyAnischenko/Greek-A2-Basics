# B1·04 · Aspect (Όψη) — one event or many

*Ενότητα 3 slot 2 (υποτακτική), Ενότητα 7 both slots (προστακτική, μέλλοντας).*

**A2 had** θα and να with one form each, and the imperative as a single list.

**B1 adds** the choice that sits underneath all three. Greek does not ask *when* only —
it asks **whether you mean one complete event or a repeated / ongoing one**, and you answer
with the **stem you pick**. The same split appears in the subjunctive, the imperative and
the future, so it is one lesson, not three.

This is the spine of B1. Nothing in the A2 area prepares you for it.

## 1 · The one idea

| | **Μη συνοπτικό** — ongoing, repeated, habitual | **Συνοπτικό** — one whole event |
|---|---|---|
| stem | the **present** stem | the **aorist** stem |
| subjunctive | να **μαγειρεύω** | να **μαγειρέψω** |
| imperative | **μαγείρευε** / μη μαγειρεύεις | **μαγείρεψε** / μη μαγειρέψεις |
| future | θα **μαγειρεύω** | θα **μαγειρέψω** |

The book gives the time words that force each choice:

| picks **μη συνοπτικό** | picks **συνοπτικό** |
|---|---|
| τώρα · όλο τον χρόνο · όλη τη μέρα / τη βδομάδα / την ώρα | τώρα · σε λίγο · αύριο |
| κάθε μέρα / πρωί / χρόνο / βδομάδα | την επόμενη βδομάδα / μέρα / χρονιά |
| το πρωί (as a routine) | τον επόμενο μήνα / χρόνο · σε λίγες μέρες |

⚠ **τώρα sits in both columns.** The adverb does not decide it — your meaning does.

## 2 · Υποτακτική

| | Συνοπτική — once | Μη συνοπτική — habitually |
|---|---|---|
| Σήμερα πρέπει **να ξυπνήσω** πολύ νωρίς. | | Κάθε μέρα πρέπει **να ξυπνάω** πολύ νωρίς. |
| Πρέπει **να προσέξω** την εμφάνισή μου στη γιορτή. | | Στη δουλειά πρέπει γενικά **να προσέχω** την εμφάνισή μου. |
| Θέλω **να βγω** με τη Γιώτα απόψε. | | Θέλω **να βγαίνω** με τη Γιώτα συχνά. |
| Μπορώ **να μαγειρέψω** εγώ σήμερα. | | Μπορώ **να μαγειρεύω** κάθε μέρα. |
| Είναι δυνατό **να σε δω** το Σάββατο; | | Είναι δυνατό **να σε βλέπω** κάθε Σάββατο; |

### ⚠ Verbs that always take the μη συνοπτική

After these, the choice is made for you — the **present** stem, always:

| | |
|---|---|
| **αισθάνομαι** | Αισθάνομαι **να πονάει** το σώμα μου όταν κάνω γυμναστική. |
| **ακούω** | Δεν την άκουσα **να παίζει** κιθάρα. |
| **αρχίζω** | Άρχισα **να τραγουδάω** από πολύ μικρός. |
| **βλέπω** | Δεν την είδα **να παίζει** στο θέατρο. |
| **κουράζομαι** | Δεν κουράστηκες **να βλέπεις** τηλεόραση όλη τη μέρα; |
| **μαθαίνω** | Έμαθα **να μιλάω** αγγλικά από έξι χρονών. |
| **μου αρέσει** | Μου αρέσει **να μαζεύω** γραμματόσημα. |
| **σταματάω** | Σταμάτησα **να παίζω** μπάσκετ πριν από δύο χρόνια. |
| **συνεχίζω** | Συνεχίζω **να πηγαίνω** στον κινηματογράφο κάθε Πέμπτη. |
| **συνηθίζω** | Δεν συνηθίζω **να πηγαίνω** στο θέατρο. |
| **ξέρω** | Ξέρεις **να παίζεις** πιάνο; |
| **παύω** | Έπαψα **να βλέπω** ταινίες τρόμου. |

The sense they share: all of them describe **watching, hearing, starting, stopping or
knowing how to do** something — and each of those takes time, so the verb inside takes the
ongoing stem.

## 3 · Προστακτική

Both aspects, and both a positive and a negative, in all four corners.

| | μη συνοπτική | συνοπτική |
|---|---|---|
| **κατεβάζω** | κατέβαζε / μην κατεβάζεις · κατεβάζετε / μην κατεβάζετε | κατέβασε / μην κατεβάσεις · κατεβάστε / μην κατεβάσετε |
| **ρίχνω** | ρίχνε / μη ρίχνεις · ρίχνετε / μη ρίχνετε | ρίξε / μη ρίξεις · ρίξτε / μη ρίξετε |
| **χτυπάω** | χτύπα / μη χτυπάς · χτυπάτε / μη χτυπάτε | χτύπησε / μη χτυπήσεις · χτυπήστε / μη χτυπήσετε |
| **γελάω** | γέλα / μη γελάς · γελάτε / μη γελάτε | γέλασε / μη γελάσεις · γελάστε / μη γελάσετε |
| **φοράω** | φόρα / μη φοράς · φοράτε / μη φοράτε | φόρεσε / μη φορέσεις · φορέστε / μη φορέσετε |
| **τοποθετώ** | — / μην τοποθετείς · τοποθετείτε / μην τοποθετείτε | τοποθέτησε / μην τοποθετήσεις · τοποθετήστε / μην τοποθετήσετε |
| **τρώω** | τρώγε / μην τρως · τρώτε / μην τρώτε | φάε / μη φας · φάτε / μη φάτε |
| **ακούω** | άκου, άκουγε / μην ακούς · ακούτε / μην ακούτε | άκουσε / μην ακούσεις · ακούστε / μην ακούσετε |
| **λέω** | λέγε / μη λες · λέγετε, λέτε / μη λέτε | πες / μην πεις · πείτε, πέστε / μην πείτε |
| **τρέχω** | τρέχα / μην τρέχεις · τρέχτε, τρεχάτε / μην τρέχετε | τρέξε / μην τρέξεις · τρέξτε / μην τρέξετε |

⚠ **The negative is never an imperative.** *μην κατεβάσεις*, *μη ρίξεις*, *μη φας* — all
of them are **να-forms with the να dropped**. There is no negative imperative in Greek.

### The irregular συνοπτική imperatives

Learn these as words. Most are one syllable and none is predictable.

| | | | |
|---|---|---|---|
| ανεβαίνω → **ανέβα** / ανεβείτε | αφήνω → **άφησε, άσε** / αφήστε | βάζω → **βάλε** / βάλτε | βγάζω → **βγάλε** / βγάλτε |
| βγαίνω → **βγες** / βγείτε | βλέπω → **δες** / δείτε | βρίσκω → **βρες** / βρείτε | γίνομαι → **γίνε** / γίνετε |
| δίνω → **δώσε** / δώστε | έρχομαι → **έλα** / ελάτε | θυμάμαι → **θυμήσου** / θυμηθείτε | κάνω → **κάνε** / κάνετε, κάντε |
| κάθομαι → **κάθισε, κάτσε** / καθίστε | κατεβαίνω → **κατέβα** / κατεβείτε | κοιμάμαι → **κοιμήσου** / κοιμηθείτε | μαθαίνω → **μάθε** / μάθετε |
| μένω → **μείνε** / μείνετε | μπαίνω → **μπες** / μπείτε | παίρνω → **πάρε** / πάρτε | περιμένω → **περίμενε** / περιμένετε |
| πίνω → **πιες** / πιείτε | πηγαίνω → **πήγαινε, πάνε** / πηγαίνετε, πάτε | πλένω → **πλύνε** / πλύν(ε)τε | στέλνω → **στείλε** / στείλ(ε)τε |
| φέρνω → **φέρε** / φέρτε | φεύγω → **φύγε** / φύγετε | | |

⚠ **έλα, πες, δες, βγες, μπες, βρες, πιες** — the short ones you hear constantly. Their
negatives are regular να-forms: *μην έρθεις, μην πεις, μη δεις, μη βγεις, μην μπεις,
μη βρεις, μην πιεις*.

## 4 · Μέλλοντας — three of them

| | Συνοπτικός<br>*αύριο, μετά* | Μη συνοπτικός<br>*repetition, duration* | Συντελεσμένος<br>*finished before a point* |
|---|---|---|---|
| form | θα + aorist stem | **θα + ενεστώτας** | **θα + παρακείμενος** |
| | **Θα φάτε** σοκολάτα και **θα λειτουργήσει** καλύτερα η καρδιά σας. | **Θα τρώτε** σοκολάτα και **θα λειτουργεί** καλύτερα η καρδιά σας. | Στο τέλος της έρευνας οι ερευνητές **θα έχουν συγκεντρώσει** πολλά στοιχεία. |
| | **Θα έρθω** αύριο να σε δω. | **Θα έρχομαι** κάθε μέρα να σε βλέπω. | Μέχρι το τέλος του χρόνου **θα έχω έρθει** στην Ελλάδα. |
| | Το απόγευμα **θα πάω** στο νοσοκομείο. | Όλο τον μήνα **θα πηγαίνω** στο νοσοκομείο. | **Θα έχω μαγειρέψει** πριν γυρίσεις από το γραφείο. |
| | Αν βγεις έξω χωρίς μπουφάν, **θα αρρωστήσεις**. | Αν βγαίνεις έξω χωρίς μπουφάν, **θα αρρωσταίνεις** συνέχεια. | Ως τη Δευτέρα **θα έχω αρχίσει** γυμναστική. |

### μαγειρεύω, all three, straight down

| Συνοπτικός | Μη συνοπτικός | Συντελεσμένος |
|---|---|---|
| θα μαγειρέψω | θα μαγειρεύω | θα έχω μαγειρέψει |
| θα μαγειρέψεις | θα μαγειρεύεις | θα έχεις μαγειρέψει |
| θα μαγειρέψει | θα μαγειρεύει | θα έχει μαγειρέψει |
| θα μαγειρέψουμε | θα μαγειρεύουμε | θα έχουμε μαγειρέψει |
| θα μαγειρέψετε | θα μαγειρεύετε | θα έχετε μαγειρέψει |
| θα μαγειρέψουν | θα μαγειρεύουν | θα έχουν μαγειρέψει |

⚠ **The συντελεσμένος is the only genuinely new tense here** — *θα έχω μαγειρέψει*,
"I will have cooked". It answers **πριν / μέχρι / ως**: finished *before* some future point.
The other two columns are stems you already have, used with θα.

## 5 · Drill

| Say in Greek | Answer |
|---|---|
| I want to go out with her tonight | Θέλω να βγω μαζί της απόψε |
| I want to go out with her often | Θέλω να βγαίνω μαζί της συχνά |
| I can cook today | Μπορώ να μαγειρέψω σήμερα |
| I can cook every day | Μπορώ να μαγειρεύω κάθε μέρα |
| I started singing as a child | Άρχισα να τραγουδάω από μικρός |
| Do you know how to play the piano? | Ξέρεις να παίζεις πιάνο; |
| Come here! | Έλα εδώ! |
| Don't come! | Μην έρθεις! |
| Tell me! | Πες μου! |
| Sit down! | Κάτσε! / Καθίστε! |
| Eat! (once) | Φάε! |
| Eat! (habitually) | Τρώγε! |
| Don't eat that! | Μη φας αυτό! |
| I'll come tomorrow | Θα έρθω αύριο |
| I'll come every day | Θα έρχομαι κάθε μέρα |
| I'll have cooked before you get back | Θα έχω μαγειρέψει πριν γυρίσεις |
| By Monday I'll have started the gym | Ως τη Δευτέρα θα έχω αρχίσει γυμναστική |
