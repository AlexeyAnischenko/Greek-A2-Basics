# Greek A2 — Grammar Drill Sheets

Modern Greek (Νέα Ελληνικά) grammar for A1→A2, written as **tables you can cover and recite**.
No prose explanation longer than a line. Every ending you need is in a cell.

Scope is **A2 only**. Anything that belongs to B1 has been left out on purpose, so if a rule is
not here, you do not need it yet.

> Mirror of the Preply canvas (22 pages). Page numbers below are canvas pages.

## How to drill

1. **Cover the right column**, read the left, say the answer out loud.
2. Do one table per sitting. Repeat yesterday's table first (2 minutes).
3. When a table is 100% cold-recall twice in a row, move it to the "monthly" pile.
4. Verbs: always drill **all six persons in one breath** — γράφω-γράφεις-γράφει-γράφουμε-γράφετε-γράφουν.

## Notation used everywhere

| Symbol | Meaning |
|---|---|
| **Nominative, Accusative, Genitive, Vocative** | The four cases — explained on page 5 |
| **1st-3rd person singular / plural** | Person labels in verb tables |
| **A / B1 / B2** | Verb group (A = γράφω, B1 = αγαπάω, B2 = μπορώ) |
| **M / F / N** | Masculine, feminine, neuter |
| ( ) | optional form, both are correct |
| ⚠ | irregular, or a common trap |
| ✦ | more words that follow the same pattern |

In the canvas, gender-marked rows and columns are colour-banded: **masculine = light blue**,
**feminine = light purple**, **neuter = light green**.

⚠ Note: **B1 / B2** in the verb tables means *verb conjugation group*, not language level.
