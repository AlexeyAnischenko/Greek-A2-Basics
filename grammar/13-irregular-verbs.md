# 13 · Irregular Verbs — the A2 master list

Columns: **Present** · **Aorist** (1st singular past) · **Dependent** (να-form) · **Imperative** (2nd singular / plural).
The dependent column is also what you need for **θα** (future) and, with **-ει**, for **έχω** (perfect).

## Impersonal verbs (3rd person only)

| Greek | Meaning | Past | Structure |
|---|---|---|---|
| **πρέπει** | must | έπρεπε | Πρέπει **να** πάω. |
| **μπορεί** | maybe | μπορούσε | Μπορεί **να** βρέχει. |
| **χρειάζεται** | it is needed | χρειαζόταν | Χρειάζεται **να** φύγουμε. |
| **αξίζει** | it is worth | άξιζε | Αξίζει **να** το δεις. |
| **βρέχει** | it rains | έβρεξε | Βρέχει πολύ. |
| **χιονίζει** | it snows | χιόνισε | Χιονίζει. |
| **κάνει ζέστη / κρύο** | it is hot / cold | έκανε | Κάνει ζέστη. |
| **φαίνεται** | it seems | φάνηκε | Φαίνεται **ότι**… |
| **συμβαίνει** | it happens | συνέβη | Τι συμβαίνει; |
| **υπάρχει / υπάρχουν** | there is / there are | υπήρχε / υπήρχαν | **Υπάρχει** πρόβλημα. |

## ⚠ The μου αρέσει construction (indirect-object verbs)

Structure: **weak genitive pronoun + verb in 3rd person + the thing**

| Greek | Literally | English |
|---|---|---|
| **Μου αρέσει** ο καφές. | to-me pleases the coffee | I like coffee. |
| **Μου αρέσουν** τα βιβλία. | to-me please the books | I like books. |
| **Σου αρέσει** να διαβάζεις; | | Do you like reading? |
| **Δεν μου αρέσει** αυτό. | | I do not like this. |
| **Μου άρεσε** πολύ. | | I liked it a lot. |
| **Μου φαίνεται** εύκολο. | | It seems easy to me. |
| **Μου λείπεις.** | to-me you-are-missing | I miss you. |
| **Μου πονάει** το κεφάλι. | to-me hurts the head | My head hurts. |
| **Μου χρειάζεται** χρόνος. | | I need time. |
| **Μου πάει** αυτό το χρώμα. | | This colour suits me. |

⚠ The **thing liked is the grammatical subject** — the verb agrees with **it**, not with the person.
