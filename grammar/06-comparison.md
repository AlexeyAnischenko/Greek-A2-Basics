# 06 · Comparison & Adverbs (Παραθετικά · Επιρρήματα)

## 1. Comparative — at A2, use πιο

| Formula | Example |
|---|---|
| **πιο** + adjective | Είναι **πιο** ψηλός. Είναι **πιο** ακριβό. |

The adjective still agrees with its noun: **πιο** ψηλ**ός** / ψηλ**ή** / ψηλ**ό**.

⚠ **Never** combine two comparatives: ~~πιο ψηλότερος~~.

## 2. "than" — από + accusative

| Greek | English |
|---|---|
| Ο Γιάννης είναι πιο ψηλός **από** τη Μαρία. | John is taller than Maria. |
| Είναι πιο ψηλός **από μένα**. | …than me. |
| Αυτό είναι πιο φτηνό **από** εκείνο. | This is cheaper than that one. |

⚠ After **από** use the **strong** pronoun: από **μένα**, από **σένα**, από **αυτόν**.

## 3. Superlative — article + πιο

| Formula | Example |
|---|---|
| article + **πιο** + adjective | Είναι **ο πιο** ψηλός μαθητής. |
| | Αυτό είναι **το πιο** ακριβό. |
| "…of all" | Είναι **ο πιο** καλός **απ' όλους**. |

For "very / extremely", A2 uses **πολύ** or **πάρα πολύ**: πολύ ψηλός, πάρα πολύ ακριβό.

## 4. Irregular comparison ⚠ memorise these four

These are so common that A2 expects them.

| Adjective | Comparative | Superlative |
|---|---|---|
| **καλός** (good) | **καλύτερος** | ο καλύτερος |
| **κακός** (bad) | **χειρότερος** | ο χειρότερος |
| **μεγάλος** (big) | **μεγαλύτερος** | ο μεγαλύτερος |
| **μικρός** (small) | **μικρότερος** | ο μικρότερος |

Also useful: **πολύς** → **περισσότερος** (more) · **λίγος** → **λιγότερος** (less).

Adverb forms: καλά→**καλύτερα**, άσχημα→**χειρότερα**, πολύ→**περισσότερο**, λίγο→**λιγότερο**.

## 5. Equality

| Structure | Example |
|---|---|
| **τόσο… όσο** (as… as) | Είναι **τόσο** ψηλός **όσο** εγώ. |
| **ίδιος… με** (the same as) | Έχω το **ίδιο** βιβλίο **με** σένα. |
| **σαν** (like) | Είναι **σαν** αδερφός μου. |
| **λίγο / αρκετά / πολύ / πάρα πολύ** | λίγο κρύο → πάρα πολύ κρύο |

## 6. Adverbs from adjectives

| Rule | Adjective | Adverb |
|---|---|---|
| **-ος → -α** (this is the A2 rule) | καλός | καλ**ά** |
| | γρήγορος | γρήγορ**α** |
| | εύκολος | εύκολ**α** |
| | ωραίος | ωραί**α** |

⚠ **Trap:** **καλός** (adjective) vs **καλά** (adverb).
Είμαι **καλός** = I'm a good person. Είμαι **καλά** = I'm fine.

A few common adverbs end in **-ως** and are simply learned as words:
**ακριβώς** (exactly), **βεβαίως** (certainly), **ευτυχώς** (fortunately), **δυστυχώς** (unfortunately).

## 7. Everyday adverbs by category

| Time | Place | Manner | Quantity |
|---|---|---|---|
| τώρα (now) | εδώ (here) | καλά (well) | πολύ (a lot) |
| μετά (after) | εκεί (there) | άσχημα (badly) | λίγο (a little) |
| πριν (before) | πάνω (up) | γρήγορα (fast) | αρκετά (enough) |
| σήμερα (today) | κάτω (down) | αργά (slowly / late) | καθόλου (not at all) |
| αύριο (tomorrow) | μέσα (inside) | μαζί (together) | σχεδόν (almost) |
| χθες (yesterday) | έξω (outside) | μόνο (only) | πάρα πολύ (too much) |
| πάντα (always) | δεξιά (right) | έτσι (like this) | περισσότερο (more) |
| ποτέ (never) | αριστερά (left) | ξανά (again) | λιγότερο (less) |
| συχνά (often) | κοντά (near) | σιγά (quietly) | τόσο (so) |
| σπάνια (rarely) | μακριά (far) | ήσυχα (calmly) | |
| ακόμα (still / yet) | παντού (everywhere) | δυνατά (loudly) | |
| ήδη (already) | πουθενά (nowhere) | | |
