## 2. ⚠ Which numbers DECLINE

Only **1, 3, 4**, the **hundreds** and **1000** change form. Everything else is invariable.

### 1 — ένας / μία / ένα

| | Masculine | Feminine | Neuter |
|---|---|---|---|
| Nominative | ένας | μία / μια | ένα |
| Accusative | έναν | μία / μια | ένα |
| Genitive | ενός | μίας / μιας | ενός |

### 3 — τρεις / τρία

| | Masculine | Feminine | Neuter |
|---|---|---|---|
| Nominative / Accusative | τρεις | τρεις | τρία |
| Genitive | τριών | τριών | τριών |

### 4 — τέσσερις / τέσσερα

| | Masculine | Feminine | Neuter |
|---|---|---|---|
| Nominative / Accusative | τέσσερις | τέσσερις | τέσσερα |
| Genitive | τεσσάρων | τεσσάρων | τεσσάρων |

### Hundreds & 1000 — decline like -ος / -ες / -α adjectives

| Neuter (default) | Masculine | Feminine |
|---|---|---|
| διακόσι**α** | διακόσι**οι** | διακόσι**ες** |
| πεντακόσι**α** | πεντακόσι**οι** | πεντακόσι**ες** |
| χίλι**α** | χίλι**οι** | χίλι**ες** |

| Examples | Meaning |
|---|---|
| **τρεις** άντρες / **τρεις** γυναίκες / **τρία** παιδιά | 3 men / women / children |
| **τέσσερις** μέρες | 4 days |
| **διακόσιες** ώρες | 200 hours |
| **χίλια** ευρώ | 1000 euros |
| **χίλιες** φορές | 1000 times |
| δύο **χιλιάδες** άνθρωποι | 2000 people (χιλιάδα is a feminine noun) |

⚠ **εκατό → εκατόν** before another number: εκατόν είκοσι πέντε.
⚠ **δύο** never declines: δύο άντρες, δύο γυναίκες, των δύο.

## 5. Telling the time

**Τι ώρα είναι;** — What time is it?

| Clock | Greek |
|---|---|
| 1:00 | Είναι **μία** (η ώρα). ⚠ feminine |
| 2:00 | Είναι **δύο**. |
| 3:00 | Είναι **τρεις**. ⚠ feminine |
| 4:00 | Είναι **τέσσερις**. ⚠ feminine |
| 5:10 | Πέντε **και δέκα**. |
| 5:15 | Πέντε **και τέταρτο**. |
| 5:30 | Πέντε **και μισή**. |
| 5:45 | Έξι **παρά τέταρτο**. |
| 5:50 | Έξι **παρά δέκα**. |
| 12:00 (noon) | **Δώδεκα το μεσημέρι**. |
| 00:00 | **Δώδεκα τα μεσάνυχτα**. |
| 08:00 | Οχτώ **το πρωί**. |
| 18:00 | Έξι **το απόγευμα**. |
| 22:00 | Δέκα **το βράδυ**. |

**At what time?** → answer with **στις**: Στις οχτώ. Στη μία. Στις τρεις και μισή.

| Greek | English |
|---|---|
| **στις** πέντε | at five |
| **στη** μία | at one |
| **σε** μισή ώρα | in half an hour |
| **από** τις 9 **μέχρι** τις 5 | from 9 to 5 |
| ακριβώς | exactly / sharp |
| περίπου / κατά τις | about / around |
