# 16 · Conjunctions & Connectors (Σύνδεσμοι)

## 1. A2 core — joining two equal parts

| Greek | English | Example |
|---|---|---|
| **και / κι** | and | κι before a vowel: **κι** εγώ |
| **ή** | or | Καφέ **ή** τσάι; |
| **αλλά / μα** | but | Θέλω, **αλλά** δεν μπορώ. |
| **όμως** | however | Είναι ακριβό, **όμως** το θέλω. |
| **ούτε… ούτε** | neither… nor | **Ούτε** εγώ **ούτε** εσύ. ⚠ needs δεν |
| **λοιπόν** | so, then | **Λοιπόν**, τι κάνουμε; |
| **επίσης** | also | **Επίσης** θέλω νερό. |
| **δηλαδή** | that is, I mean | Είμαι φοιτητής, **δηλαδή** σπουδάζω. |

## 2. A2 core — subordinating

### With a normal verb (indicative)

| Greek | English | Example |
|---|---|---|
| **ότι / πως** | that (reported speech) | Λέει **ότι** έρχεται. |
| **γιατί / επειδή** | because | Δεν ήρθα **επειδή** ήμουν άρρωστος. |
| **όταν** | when | **Όταν** ήρθε, έφυγα. |
| **ενώ** | while | **Ενώ** διάβαζα, ήρθε. |
| **μόλις** | as soon as | **Μόλις** έφτασα, τηλεφώνησα. |
| **που** | that / which | Ο άντρας **που** ήρθε. Χάρηκα **που** σε είδα. |
| **όπως** | as / the way | Κάνε **όπως** θέλεις. |

### With να (subjunctive — see page 12)

| Greek | English | Example |
|---|---|---|
| **να** | that / to | Θέλω **να** φύγω. |
| **για να** | in order to | Ήρθα **για να** σε δω. |
| **πριν (να)** | before | **Πριν** φύγεις, πες μου. |
| **χωρίς να** | without -ing | Έφυγε **χωρίς να** μιλήσει. |
| **μέχρι να** | until | Περίμενε **μέχρι να** έρθω. |

### Conditional

| Greek | English | Example |
|---|---|---|
| **αν / εάν** | if | **Αν** έχω χρόνο, θα έρθω. ⚠ never αν + θα |
| **άμα** | if (colloquial) | **Άμα** θέλεις, πάμε. |

## 3. ⚠ Confusable pairs (pure A2 exam material)

| Pair | Difference |
|---|---|
| **που** (that / which) vs **πού** (where?) | Το σπίτι **που** μένω. / **Πού** μένεις; |
| **πως** (that) vs **πώς** (how?) | Λέει **πως** ήρθε. / **Πώς** είσαι; |
| **γιατί** (because) vs **γιατί;** (why?) | Δεν ήρθα **γιατί**… / **Γιατί** δεν ήρθες; |
| **όταν** (when, factual) vs **αν** (if) | **Όταν** έρθει, θα φάμε. / **Αν** έρθει… |
| **και** (and) vs **κι** (before a vowel) | **και** ο Γιάννης / **κι** εγώ |
| **σαν** (like) vs **ως** (as, in the role of) | Είναι **σαν** παιδί. / Δουλεύει **ως** γιατρός. |

## 4. Reported speech (A2)

| Direct | Reported |
|---|---|
| «Είμαι κουρασμένος.» | Είπε **ότι** είναι / ήταν κουρασμένος. |
| «Θα έρθω.» | Είπε **ότι** θα έρθει. |
| «Πού μένεις;» | Με ρώτησε **πού** μένω. |
| «Έλα!» | Μου είπε **να** έρθω. |
| «Μην πας.» | Μου είπε **να μην** πάω. |
| «Ήρθες;» | Με ρώτησε **αν** ήρθα. |

⚠ Tense backshift is optional in Greek — Είπε ότι είναι κουρασμένος is perfectly normal.

## 5. Discourse connectors that make you sound natural (A2)

| Greek | English |
|---|---|
| **Λοιπόν…** | So… / Well… |
| **Πρώτα** | First |
| **Μετά / Ύστερα** | Then / afterwards |
| **Στο τέλος / Τελικά** | In the end |
| **Επίσης** | Also |
| **Δηλαδή** | I mean / that is |
| **Εντάξει** | OK |
| **Βασικά** | Basically |
| **Για παράδειγμα** | For example |
| **Νομίζω ότι…** | I think that… |
| **Κατά τη γνώμη μου** | In my opinion |
| **Συμφωνώ / Διαφωνώ** | I agree / I disagree |
| **Ίσως / Μπορεί** | Maybe |
| **Φυσικά / Βέβαια** | Of course |
| **Δυστυχώς / Ευτυχώς** | Unfortunately / fortunately |
| **Καθόλου** | Not at all |
