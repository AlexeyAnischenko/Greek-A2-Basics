# 02 · Nouns (Ουσιαστικά) — the A2 declensions

⚠ New to cases? **What each case actually does is on page 5** — read that first if Nominative /
Accusative / Genitive / Vocative mean nothing to you yet.

**Gender is not guessable from meaning — learn every noun with its article.**
Quick heuristic (about 85% reliable):

| Ending | Usually | Example |
|---|---|---|
| -ος, -ας, -ης, -ες, -ους | masculine | ο δρόμος, ο άντρας, ο μαθητής, ο καφές, ο παππούς |
| -α, -η, -ού | feminine | η ώρα, η νίκη, η αλεπού |
| -ο, -ι, -μα | neuter | το βιβλίο, το παιδί, το μάθημα |

## Master grid — every article and ending in one table

Article **and** ending, all three cases, singular and plural, in one place. Each singular cell gives **the definite article / the indefinite article**, then the ending. Each type is expanded
with full examples further down the page. Rows are colour-banded: **masculine** light blue,
**feminine** light purple, **neuter** light green.

| **M1 · -ας** — ο άντρας | ο / ένας **-ας** | τον / έναν **-α** | του / ενός **-α** | οι **-ες** | τους **-ες** | των **-ών** |
| **M2 · -ης** — ο μαθητής | ο / ένας **-ής** | τον / έναν **-ή** | του / ενός **-ή** | οι **-ές** | τους **-ές** | των **-ών** |

| **M4 · -ές** — ο καφές | ο / ένας **-ές** | τον / έναν **-έ** | του / ενός **-έ** | οι **-έδες** | τους **-έδες** | των **-έδων** |
| **M4 · -ούς** — ο παππούς | ο / ένας **-ούς** | τον / έναν **-ού** | του / ενός **-ού** | οι **-ούδες** | τους **-ούδες** | των **-ούδων** |

| **N4 · -ος** — το λάθος | το / ένα **-ος** | το / ένα **-ος** | του / ενός **-ους** | τα **-η** | τα **-η** | των **-ών** |

What the grid shows at a glance:

| Pattern | Where it holds |
|---|---|
| Accusative singular = nominative **minus the final -ς** | every masculine type |
| Nominative = accusative, always | every neuter type, singular **and** plural |
| The singular changes only the **article** | F1, F2, F3 — nominative and accusative keep the same ending |
| Genitive plural is **-ων / -ών** | everywhere except F3 (**-εων**) and the -δ- types (**-δων**) |
| There is no indefinite article in the plural | Greek simply drops it: Βλέπω παιδιά. = I see (some) children. |
| Genitive singular is where the genders differ most | M **-α / -ή / -ου**, F **-ας / -ης**, N **-ου / -ιού / -ματος** |

⚠ **μία / μια** and **μίας / μιας** are both correct — the short form in the grid is the everyday one. ⚠ Vocative is left out on purpose — it is only for calling someone, and it is in the per-type
tables below. ⚠ **τον** and **την** drop the **-ν** before some consonants (page 3); masculine
**τον** is kept in writing because it is what separates τον δρόμο from το δρόμο.

## MASCULINE

### M1 · -ας (ο άντρας — man) ✦ also: ο πατέρας, ο μήνας, ο χειμώνας

| | Singular | Plural |
|---|---|---|
| Nominative | ο άντρ**ας** | οι άντρ**ες** |
| Accusative | τον άντρ**α** | τους άντρ**ες** |
| Genitive | του άντρ**α** | των αντρ**ών** |
| Vocative | άντρ**α**! | άντρ**ες**! |

### M2 · -ης (ο μαθητής — pupil) ✦ also: ο εργάτης, ο πολίτης, ο κλέφτης

| | Singular | Plural |
|---|---|---|
| Nominative | ο μαθητ**ής** | οι μαθητ**ές** |
| Accusative | τον μαθητ**ή** | τους μαθητ**ές** |
| Genitive | του μαθητ**ή** | των μαθητ**ών** |
| Vocative | μαθητ**ή**! | μαθητ**ές**! |

### M3 · -ος (ο δρόμος — street) ✦ also: ο άνθρωπος, ο φίλος, ο ουρανός, ο γιατρός

| | Singular | Plural |
|---|---|---|
| Nominative | ο δρόμ**ος** | οι δρόμ**οι** |
| Accusative | τον δρόμ**ο** | τους δρόμ**ους** |
| Genitive | του δρόμ**ου** | των δρόμ**ων** |
| Vocative | δρόμ**ε**! | δρόμ**οι**! |

⚠ **Stress shift** in three-syllable -ος words stressed on the third-from-last:
ο **ά**νθρωπος → του ανθρ**ώ**που, των ανθρ**ώ**πων, τους ανθρ**ώ**πους
(the nominative plural keeps it: οι **ά**νθρωποι)

### M4 · -ες / -ους (ο καφές, ο παππούς) — "add -δ-"

| | ο καφές | ο παππούς |
|---|---|---|
| Nominative singular | ο καφ**ές** | ο παππ**ούς** |
| Accusative / Genitive singular | τον / του καφ**έ** | τον / του παππ**ού** |
| Nominative / Accusative plural | οι / τους καφ**έδες** | οι / τους παππ**ούδες** |
| Genitive plural | των καφ**έδων** | των παππ**ούδων** |

✦ also: ο μπακλαβάς→μπακλαβάδες, ο ψαράς→ψαράδες

## FEMININE

### F1 · -α (η ώρα — hour) ✦ also: η γλώσσα, η θάλασσα, η μητέρα, η καρέκλα

| | Singular | Plural |
|---|---|---|
| Nominative | η ώρ**α** | οι ώρ**ες** |
| Accusative | την ώρ**α** | τις ώρ**ες** |
| Genitive | της ώρ**ας** | των ωρ**ών** |
| Vocative | ώρ**α**! | ώρ**ες**! |

### F2 · -η (η νίκη — victory) ✦ also: η ζάχαρη, η αγάπη, η τέχνη, η αδερφή

| | Singular | Plural |
|---|---|---|
| Nominative | η νίκ**η** | οι νίκ**ες** |
| Accusative | τη νίκ**η** | τις νίκ**ες** |
| Genitive | της νίκ**ης** | των νικ**ών** |

### F3 · -η → -εις (η πόλη — city) ⚠ high-frequency, learn it

✦ also: η τάξη, η λέξη, η στάση, η σκέψη, η δύναμη, η άσκηση, η κυβέρνηση

| | Singular | Plural |
|---|---|---|
| Nominative | η πόλ**η** | οι πόλ**εις** |
| Accusative | την πόλ**η** | τις πόλ**εις** |
| Genitive | της πόλ**ης** | των πόλ**εων** |

### F4 · -ού (η αλεπού — fox) ✦ also: η γιαγιά (→γιαγιάδες), η μαϊμού

| | Singular | Plural |
|---|---|---|
| Nominative / Accusative | η / την αλεπ**ού** | οι / τις αλεπ**ούδες** |
| Genitive | της αλεπ**ούς** | των αλεπ**ούδων** |

## NEUTER

### N1 · -ο (το βιβλίο — book) ✦ also: το δέντρο, το αυτοκίνητο, το πρόσωπο

| | Singular | Plural |
|---|---|---|
| Nominative / Accusative / Vocative | το βιβλί**ο** | τα βιβλί**α** |
| Genitive | του βιβλί**ου** | των βιβλί**ων** |

⚠ Stress shift: το **αυ**τοκίνητο → των αυτοκιν**ή**των.

### N2 · -ι (το παιδί — child) ✦ also: το σπίτι, το τραπέζι, το ψωμί, το κρασί

The genitive inserts **-ού**:

| | Singular | Plural |
|---|---|---|
| Nominative / Accusative | το παιδ**ί** | τα παιδι**ά** |
| Genitive | του παιδι**ού** | των παιδι**ών** |

### N3 · -μα (το μάθημα — lesson) ✦ also: το πρόβλημα, το όνομα, το πράγμα, το γράμμα

Insert **-ματ-**:

| | Singular | Plural |
|---|---|---|
| Nominative / Accusative | το μάθη**μα** | τα μαθή**ματα** |
| Genitive | του μαθή**ματος** | των μαθη**μάτων** |

⚠ The stress moves right in every form except the nominative / accusative singular.

### N4 · -ος neuter (το λάθος — mistake) — only a few words, but common

✦ also: το μέρος, το δάσος, το κράτος, το έθνος

| | Singular | Plural |
|---|---|---|
| Nominative / Accusative | το λάθ**ος** | τα λάθ**η** |
| Genitive | του λάθ**ους** | των λαθ**ών** |
