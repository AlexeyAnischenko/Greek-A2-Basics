# 10 · Perfect Tense (Παρακείμενος)

## 1. The invariable form — it never changes

Take the dependent (να-) stem from page 11 and add **-ει**.

| Verb | Dependent (να-form) | Invariable form |
|---|---|---|
| γράφω | να γράψω | **γράψει** |
| διαβάζω | να διαβάσω | **διαβάσει** |
| μιλάω | να μιλήσω | **μιλήσει** |
| μπορώ | να μπορέσω | **μπορέσει** |
| πληρώνω | να πληρώσω | **πληρώσει** |
| βλέπω | να δω | **δει** |
| λέω | να πω | **πει** |
| πάω | να πάω | **πάει** |
| τρώω | να φάω | **φάει** |
| παίρνω | να πάρω | **πάρει** |
| δίνω | να δώσω | **δώσει** |
| έρχομαι | να έρθω | **έρθει** |
| κοιμάμαι | να κοιμηθώ | **κοιμηθεί** |
| πλένομαι | να πλυθώ | **πλυθεί** |

**Rule:** active → **-ει** · passive → **-θεί / -τεί / -στεί**. It **never agrees** with anything.

## 2. The perfect: έχω + invariable form

| Person | Form |
|---|---|
| 1st singular | **έχω** γράψει |
| 2nd singular | **έχεις** γράψει |
| 3rd singular | **έχει** γράψει |
| 1st plural | **έχουμε** γράψει |
| 2nd plural | **έχετε** γράψει |
| 3rd plural | **έχουν** γράψει |

Only **έχω** conjugates. The second word is frozen.

## 3. When to use it — and when NOT to ⚠

Greek uses the **aorist** far more than English uses the simple past. The perfect is for
**experience** and for **results that matter now**.

| Situation | Greek |
|---|---|
| Experience ("ever") | **Έχεις πάει** ποτέ στην Κρήτη; — Have you ever been to Crete? |
| Result now | **Έχω χάσει** τα κλειδιά μου. — I've lost my keys. |
| Not yet | **Δεν έχω φάει** ακόμα. — I haven't eaten yet. |
| Already | **Έχω** ήδη **διαβάσει** αυτό το βιβλίο. |

### The two traps

| English | ⚠ Wrong in Greek | ✔ Right in Greek |
|---|---|---|
| I have lived here five years | ~~Έχω μείνει εδώ πέντε χρόνια~~ | **Μένω** εδώ πέντε χρόνια. (PRESENT) |
| Yesterday I went to the cinema | ~~Χθες έχω πάει~~ | Χθες **πήγα** στο σινεμά. (AORIST) |

**Rule of thumb:** with a stated past time (χθες, πέρσι, στις 5) always use the **aorist**.
With "for / since" up to now, use the **present**.

## 4. Negation & pronoun placement

| Pattern | Example |
|---|---|
| **δεν** + έχω + invariable | **Δεν** έχω φάει. |
| pronoun between δεν and έχω | **Δεν το** έχω δει. |
| pronoun before έχω | **Του το** έχω πει. |
