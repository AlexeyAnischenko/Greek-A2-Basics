# 15 · Prepositions (Προθέσεις)

## Golden rule: every common preposition takes the ACCUSATIVE.

## 1. The core set

| Preposition | Meanings | Example |
|---|---|---|
| **σε** | in, at, to, on | Πάω **στην** Αθήνα. Είμαι **στο** σπίτι. |
| **από** | from, of, by, than, through | Έρχομαι **από** τη δουλειά. |
| **με** | with, by (means) | Πάω **με** το αυτοκίνητο. Μιλάω **με** τη Μαρία. |
| **για** | for, about, to (purpose) | Αυτό είναι **για** σένα. Μιλάμε **για** το βιβλίο. |
| **χωρίς** | without | Καφές **χωρίς** ζάχαρη. |
| **μέχρι / ως** | until, up to | **Μέχρι** τις 5. |
| **προς** | towards | Πάμε **προς** το κέντρο. |
| **κατά** | during, against, around | **Κατά** τις 6. **Κατά** τη γνώμη μου. |
| **μετά** | after | **Μετά** το μάθημα. |
| **πριν** | before | **Πριν** το φαγητό. |
| **παρά** | minus (telling the time) | Πέντε **παρά** δέκα. |
| **σαν** | like, as | Είναι **σαν** αδερφός μου. |
| **εκτός από** | except | Όλοι **εκτός από** μένα. |
| **αντί (για)** | instead of | **Αντί για** καφέ, τσάι. |
| **γύρω από** | around | **Γύρω από** το τραπέζι. |
| **μαζί με** | together with | Ήρθα **μαζί με** τον Γιάννη. |

## 2. σε + article — always contracted ⚠ must become automatic

| σε + article | Contraction | Example |
|---|---|---|
| σε + τον | **στον** | **στον** δρόμο (in the street) |
| σε + την | **στην** | **στην** Αθήνα |
| σε + το | **στο** | **στο** σπίτι |
| σε + τους | **στους** | **στους** φίλους |
| σε + τις | **στις** | **στις** 5 (at 5 o'clock) |
| σε + τα | **στα** | **στα** παιδιά |
| σε + έναν | **σ' έναν** | **σ' έναν** φίλο |
| σε + μία | **σε μια** | **σε μια** ώρα |
| σε + ένα | **σ' ένα** | **σ' ένα** μαγαζί |

**από** contracts optionally: από τον → **απ' τον**, από το → **απ' το**, από την → **απ' την**.
**με / για / σαν** may elide before a vowel: **μ' αυτόν**, **γι' αυτό**, **σ' αυτό**.

## 3. σε vs από — the direction pair

| σε (motion **to** / position **in**) | από (motion **from** / origin) |
|---|---|
| Πάω **στο** σχολείο. | Έρχομαι **από** το σχολείο. |
| Μένω **στην** Κύπρο. | Είμαι **από** την Κύπρο. |
| Το βάζω **στο** τραπέζι. | Το παίρνω **από** το τραπέζι. |
| Μιλάω **στον** Γιάννη. (to John) | Το άκουσα **από** τον Γιάννη. |
| Φτάνω **στις** 8. | Δουλεύω **από** τις 8. |

## 4. Place words

| Greek | English | Construction |
|---|---|---|
| **πάνω σε / πάνω από** | on / above | **πάνω στο** τραπέζι, **πάνω από** το κρεβάτι |
| **κάτω από** | under | **κάτω από** την καρέκλα |
| **μέσα σε** | inside | **μέσα στο** σπίτι |
| **έξω από** | outside | **έξω από** το μαγαζί |
| **μπροστά από** | in front of | **μπροστά από** την πόρτα |
| **πίσω από** | behind | **πίσω από** το κτίριο |
| **δίπλα σε** | next to | **δίπλα στο** παράθυρο |
| **απέναντι από** | opposite | **απέναντι από** την τράπεζα |
| **κοντά σε** | near | **κοντά στη** θάλασσα |
| **μακριά από** | far from | **μακριά από** το κέντρο |
| **γύρω από** | around | **γύρω από** την πλατεία |
| **στην αρχή / στο τέλος** | at the start / end | **στην αρχή** του δρόμου |

## 5. Time expressions

| Greek | English |
|---|---|
| **στις** 8 (η ώρα) | at 8 o'clock |
| **σε** δύο ώρες | in two hours |
| **από** τις 8 **μέχρι** τις 5 | from 8 to 5 |
| **τη** Δευτέρα | on Monday |
| **τον** Ιανουάριο / **το** Μάιο | in January / May |
| **το** 2026 | in 2026 |
| **το** πρωί / **το** βράδυ | in the morning / evening |
| **τη** νύχτα | at night |
| **πριν από** δύο μέρες | two days ago |
| **μετά από** μια ώρα | after an hour |
| **κατά** τις 6 | around 6 |
| **για** δύο μέρες | for two days |
| **μέσα σε** μια βδομάδα | within a week |
| **κάθε** μέρα | every day |

⚠ Days and months take the **article, not σε**: Τη Δευτέρα πάω… (not ~~στη Δευτέρα~~).

## 6. με — its four jobs

| Job | Example |
|---|---|
| accompaniment ("with") | Πάω **με** τους φίλους μου. |
| means of transport | Πάω **με** το λεωφορείο / **με** τα πόδια (on foot) |
| instrument | Γράφω **με** το μολύβι. |
| description | Το κορίτσι **με** τα μαύρα μαλλιά. Καφές **με** γάλα. |

## 7. Frequent από idioms

| Greek | English |
|---|---|
| πεθαίνω **από** πείνα | die of hunger |
| πιο ψηλός **από** μένα | taller than me |
| ένα **από** τα παιδιά | one of the children |
| περνάω **από** το κέντρο | pass through the centre |
| **από** τηλέφωνο | by phone |
| φτιαγμένο **από** ξύλο | made of wood |
| γραμμένο **από** τον Καζαντζάκη | written by Kazantzakis |
| **Από** πού είσαι; | Where are you from? |

## 8. Prepositions + weak pronouns → use the STRONG form

| Wrong | Right |
|---|---|
| ~~για με~~ | **για μένα** |
| ~~με σε~~ | **με σένα** |
| ~~από τον~~ (as a pronoun) | **από αυτόν** |
| ~~σε μας~~ | **σ' εμάς** |
