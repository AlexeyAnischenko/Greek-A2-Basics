# 09b · Aorist — passive (-θηκα)

Verbs whose present ends in **-μαι** (κοιμάμαι, θυμάμαι, σκέφτομαι, ντύνομαι…) make their aorist
with **-θηκα**. At A2 this matters less as a "passive" than as the past of the everyday -μαι
verbs: *κοιμήθηκα* — I slept, *θυμήθηκα* — I remembered.

## 1. THE ENDINGS

| Pronoun | Person | Ending |
|---|---|---|
| **εγώ** | 1st singular | **-θηκα** |
| **εσύ** | 2nd singular | **-θηκες** |
| **αυτός / αυτή / αυτό** | 3rd singular | **-θηκε** |
| **εμείς** | 1st plural | **-θήκαμε** |
| **εσείς** | 2nd plural | **-θήκατε** |
| **αυτοί / αυτές / αυτά** | 3rd plural | **-θηκαν** |

⚠ Note the **stress shift** to -θή- in the 1st and 2nd plural. There is **never an έ-**: the
-θηκα already gives every form enough syllables.

### Example: κοιμάμαι

| Pronoun | Person | Form |
|---|---|---|
| **εγώ** | 1st singular | κοιμή**θηκα** |
| **εσύ** | 2nd singular | κοιμή**θηκες** |
| **αυτός / αυτή / αυτό** | 3rd singular | κοιμή**θηκε** |
| **εμείς** | 1st plural | κοιμη**θήκαμε** |
| **εσείς** | 2nd plural | κοιμη**θήκατε** |
| **αυτοί / αυτές / αυτά** | 3rd plural | κοιμή**θηκαν** |

## 2. Passive-aorist stem table

The θ often blends with the stem consonant: **σθ → στ**, **φθ → φτ**, **χθ → χτ**.

| Present passive | Aorist passive | Examples |
|---|---|---|
| from -φ / -β / -π / -πτ | **-φτηκα / -πηκα** | γράφομαι→**γράφτηκα**, κρύβομαι→**κρύφτηκα**, σκέφτομαι→**σκέφτηκα**, επισκέπτομαι→**επισκέφτηκα**, κόβομαι→**κόπηκα** |
| from -κ / -γ / -χ | **-χτηκα** | ανοίγομαι→**ανοίχτηκα**, ρίχνομαι→**ρίχτηκα** |
| from -ζ / -σ | **-στηκα** | χρειάζομαι→**χρειάστηκα**, ξεκουράζομαι→**ξεκουράστηκα**, γνωρίζομαι→**γνωρίστηκα** |
| from -εύ | **-εύτηκα** | παντρεύομαι→**παντρεύτηκα**, ονειρεύομαι→**ονειρεύτηκα** |
| from -ν / -θ | **-θηκα** | πλένομαι→**πλύθηκα**, ντύνομαι→**ντύθηκα**, αισθάνομαι→**αισθάνθηκα** |
| -ιέμαι / -άμαι (B1/B2) | **-ήθηκα** | αγαπιέμαι→**αγαπήθηκα**, κοιμάμαι→**κοιμήθηκα**, φοβάμαι→**φοβήθηκα**, θυμάμαι→**θυμήθηκα**, λυπάμαι→**λυπήθηκα** |
| no θ at all | **-ηκα** | χαίρομαι→**χάρηκα**, φαίνομαι→**φάνηκα** |

## 3. The -μαι verbs you'll use daily

| Verb | Aorist | Meaning |
|---|---|---|
| **κοιμάμαι** | **κοιμήθηκα**, κοιμηθήκαμε | I slept |
| **θυμάμαι** | **θυμήθηκα**, θυμηθήκαμε | I remembered |
| **φοβάμαι** | **φοβήθηκα**, φοβηθήκαμε | I got scared |
| **σκέφτομαι** | **σκέφτηκα**, σκεφτήκαμε | I thought |
| **χρειάζομαι** | **χρειάστηκα**, χρειαστήκαμε | I needed |
| **φαίνομαι** | **φάνηκα**, φανήκαμε | I seemed |
| **βρίσκομαι** | **βρέθηκα**, βρεθήκαμε | I ended up / was (somewhere) |
| **επισκέπτομαι** | **επισκέφτηκα**, επισκεφτήκαμε | I visited |
| **χαίρομαι** | **χάρηκα**, χαρήκαμε | I was glad · *Χάρηκα!* — Nice to meet you! |
| **αισθάνομαι** | **αισθάνθηκα**, αισθανθήκαμε | I felt |
| **ντύνομαι** | **ντύθηκα**, ντυθήκαμε | I got dressed |
| **παντρεύομαι** | **παντρεύτηκα**, παντρευτήκαμε | I got married |

## 4. ⚠ Three -μαι verbs with ACTIVE aorist endings

| Verb | Aorist — all six persons |
|---|---|
| **έρχομαι** (come) | **ήρθα**, ήρθες, ήρθε, ήρθαμε, ήρθατε, ήρθαν |
| **γίνομαι** (become) | **έγινα**, έγινες, έγινε, γίναμε, γίνατε, έγιναν |
| **κάθομαι** (sit) | **κάθισα**, κάθισες, κάθισε, καθίσαμε, καθίσατε, κάθισαν |
