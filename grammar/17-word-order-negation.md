# 17 · Word Order, Negation & Questions

## 1. Basic order: subject–verb–object, but flexible

Case endings carry the meaning, so the order can move for emphasis.

| Greek | Emphasis |
|---|---|
| **Ο Γιάννης** αγοράζει **το βιβλίο**. | neutral |
| **Το βιβλίο** αγοράζει ο Γιάννης. | it's the BOOK he's buying |
| Αγοράζει ο Γιάννης το βιβλίο. | verb first, narrative |

Because ο Γιάννης is nominative and το βιβλίο accusative, the roles are never confused.

## 2. The verb-phrase slot order ⚠ fixed

Order: **δεν / να / θα / ας / μη** → **weak pronouns** → **verb**

| Sentence | Breakdown |
|---|---|
| **Δεν το** ξέρω. | δεν + το + verb |
| **Θα σου το** πω. | θα + σου + το + verb |
| **Να μη μας** το δώσεις. | να + μη + μας + το + verb |
| **Δεν θα σε** δω. | δεν + θα + σε + verb |
| **Δεν του το** έχω πει. | δεν + του + το + έχω + invariable |

**Two pronouns: genitive before accusative** — μου το, σου το, του τη, μας τα, σας τους.

⚠ The **only** exception: after a **positive imperative** the pronouns go **after** the verb
(Δώσε **μου το**!) — see page 13.

## 3. Negation

| Particle | Used with | Example |
|---|---|---|
| **δεν** | statements (indicative) | **Δεν** ξέρω. **Δεν** θα έρθω. **Δεν** ήρθε. |
| **μη(ν)** | after να, and in commands | **Μην** πας! Θέλω **να μην** πας. |
| **όχι** | standalone "no", or negating one word | **Όχι**, ευχαριστώ. Θέλω τσάι, **όχι** καφέ. |
| **ούτε** | not even / nor | **Ούτε** εγώ ξέρω. |

### δεν / μην keep the -ν before a vowel and before κ π τ, μπ ντ γκ, τσ τζ, ξ ψ

| Keeps -ν | Drops -ν |
|---|---|
| δε**ν** έχω | δε θέλω |
| δε**ν** πάω | — |
| μη**ν** ανοίγεις | μη μιλάς |
| μη**ν** το κάνεις | μη φεύγεις |

⚠ In practice **δεν** is almost always written in full. **μη / μην** follows the rule strictly.

### Double negation is REQUIRED

| Greek | English |
|---|---|
| **Δεν** ξέρω **τίποτα**. | I know nothing. |
| **Δεν** ήρθε **κανένας**. | Nobody came. |
| **Δεν** πάω **πουθενά**. | I'm not going anywhere. |
| **Δεν** το κάνω **ποτέ**. | I never do it. |
| **Δεν** έχω **καθόλου** λεφτά. | I have no money at all. |
| **Δεν** θέλω **ούτε** καφέ **ούτε** τσάι. | I want neither coffee nor tea. |

When the negative word comes **first**, δεν still stays:
Κανένας **δεν** ήρθε. Ποτέ **δεν** το κάνω. Τίποτα **δεν** ξέρω.

## 4. Questions

### Yes / no — same word order, only intonation (and the ; mark)

| Statement | Question |
|---|---|
| Είσαι Έλληνας. | Είσαι Έλληνας**;** |
| Θα έρθεις. | Θα έρθεις**;** |
| Μιλάς αγγλικά. | Μιλάς αγγλικά**;** |

No auxiliary "do", no inversion.

### Answering

| Greek | English |
|---|---|
| **Ναι.** | Yes. |
| **Όχι.** | No. |
| **Βέβαια / Φυσικά.** | Of course. |
| **Νομίζω.** | I think so. |
| **Δεν ξέρω.** | I don't know. |
| **Ίσως / Μπορεί.** | Maybe. |
| **Καθόλου.** | Not at all. |
| **Έτσι κι έτσι.** | So-so. |

### Question words — always first

| Word | Question |
|---|---|
| **Τι** | **Τι** κάνεις; — What are you doing? / How are you? |
| **Ποιος / Ποια / Ποιο** | **Ποιος** είναι; **Ποιον** βλέπεις; |
| **Πού** | **Πού** μένεις; |
| **Πότε** | **Πότε** θα έρθεις; |
| **Πώς** | **Πώς** σε λένε; |
| **Γιατί** | **Γιατί** δεν ήρθες; |
| **Πόσο / Πόσα / Πόσοι** | **Πόσο** κάνει; **Πόσα** παιδιά έχεις; |
| **Τίνος** | **Τίνος** είναι αυτό; |
| **Από πού** | **Από πού** είσαι; |
| **Με ποιον** | **Με ποιον** μιλάς; |
| **Τι ώρα** | **Τι ώρα** είναι; |

⚠ In questions these carry a **written accent**: πού, πώς, πότε. The same words **without** the
accent are conjunctions or relatives: που, πως. (See page 17.)

### Tags & fillers

| Greek | English |
|---|---|
| …**έτσι δεν είναι;** | …isn't it? |
| …**σωστά;** | …right? |
| …**εντάξει;** | …OK? |
| **Ορίστε;** | Sorry, what? |
| **Πώς;** | Pardon? |
| **Δηλαδή;** | Meaning? |

## 5. Adjective / possessive / demonstrative order

Order: **demonstrative → article → adjective → NOUN → possessive**

| Greek | English |
|---|---|
| **αυτό το μεγάλο** σπίτι **μου** | this big house of mine |
| **όλα τα καλά** παιδιά | all the good children |
| **εκείνη η ωραία** γυναίκα | that beautiful woman |
| **το πρώτο** μάθημα | the first lesson |

## 6. Είμαι and "there is" sentences

| Pattern | Example |
|---|---|
| subject + είμαι + **nominative** | Ο Γιάννης είναι **γιατρός**. |
| subject + είμαι + adjective (agrees) | Η Μαρία είναι **κουρασμένη**. |
| "there is / there are" | **Υπάρχει** ένα πρόβλημα. / **Υπάρχουν** πολλά. |
| "I have" | **Έχω** ένα αυτοκίνητο. |
| impersonal weather | **Κάνει** ζέστη. **Βρέχει**. |
| "it is" + adjective (neuter) | **Είναι** εύκολο. **Είναι** κρίμα. |

## 7. Emphasis toolkit (A2)

| Device | Example |
|---|---|
| Add the subject pronoun | **Εγώ** δεν το είπα! |
| Front the object | **Αυτό** θέλω! |
| **και** = "even / too" | Ήρθε **και** ο Γιάννης. |
| **μόνο** | **Μόνο** εσύ ξέρεις. |
