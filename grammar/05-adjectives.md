# 05 · Adjectives (Επίθετα)

**Rule:** the adjective agrees with its noun in **gender + case + number**, and goes **before** the noun.
ο καλός φίλος · τη μεγάλη πόλη · των ωραίων παιδιών

At A2 you need **two** patterns and two footnotes. Counted across the A2 wordlist:

| Type | A2 adjectives | Verdict |
|---|---|---|
| **A · -ος / -η / -ο** (καλός, όμορφος) | **167** | the pattern — 86% of them |
| **B · -ος / -α / -ο** (ωραίος) | **24** | learn it, it is only the feminine that differs |
| **C · -ύς / -ιά / -ύ** (πλατύς) | **1** — ελαφρύς | one word. Recognise it, do not drill it |
| **-ός / -ιά / -ό** (γλυκός) | **3** | γλυκός, ξανθός, Κρητικός |
| **-ης / -α / -ικο** (ζηλιάρης) | **0** in the wordlist | spoken Greek, not the syllabus — recognise it, that is all |
| **-ης / -ης / -ες** (διεθνής) | **0** | not an A2 type — not taught on this page |
| **D · πολύς** | grammar word | irregular and unavoidable |

## Master grid — every adjective ending in one table

Same shape as the noun grid on page 4: **one row per type and gender, grouped by gender**
(all the masculines, then the feminines, then the neuters), the three cases across the top,
each split into singular and plural. The cell holds the **ending**; hover it (or tap it) for a
sentence that uses exactly that form. Rows are colour-banded: **masculine** light blue,
**feminine** light purple, **neuter** light green.

| Type & gender | Nominative singular | Accusative singular | Genitive singular | Nominative plural | Accusative plural | Genitive plural |
|---|---|---|---|---|---|---|
| **A · -ος / -η / -ο** καλός — Masculine | **-ός** | **-ό** | **-ού** | **-οί** | **-ούς** | **-ών** |
| **B · -ος / -α / -ο** ωραίος — Masculine | **-ος** | **-ο** | **-ου** | **-οι** | **-ους** | **-ων** |

| **C · -ύς / -ιά / -ύ** ελαφριά — Feminine | **-ιά** | **-ιά** | **-ιάς** | **-ιές** | **-ιές** | **-ιών** |

| **D · πολύς** πολύ — Neuter | πολ**ύ** | πολ**ύ** | πολλ**ού** | πολλ**ά** | πολλ**ά** | πολλ**ών** |
| **Invariable** μπλε, γκρι, καφέ, ροζ — all genders | μπλε | μπλε | μπλε | μπλε | μπλε | μπλε |

⚠ **The accent in the cell is the one the row's word carries, not part of the type.** καλός is
end-stressed, so its endings show the accent; όμορφος is stem-stressed and keeps its stress
throughout — όμορφ**ος**, όμορφ**η**, όμορφ**ου**, όμορφ**ων**. Adjective stress never moves.

⚠ **ζηλιάρης is the only type whose masculine plural is not in -οι.** It takes the **-ηδες** of the masculine nouns in -ης (ο μανάβης → οι μανάβηδες), its feminine is exactly type B, and its neuter inserts **-ικ-** before the ending. No adjective of this
type is in the A2 wordlist or in the 2015–2018 exam papers — it is here to be recognised, not drilled.

⚠ **γλυκός has only one row** because only its feminine is different. Its masculine and neuter are
plain type A: γλυκός / γλυκό / γλυκού / γλυκοί / γλυκούς / γλυκών. Same for ξανθός and Κρητικός.

What the grid shows at a glance:

| Pattern | Where it holds |
|---|---|
| The **neuter** never changes between nominative and accusative | every type, singular **and** plural — same as the neuter nouns |
| The **feminine singular** never changes between nominative and accusative | every type — only the article moves |
| Masculine accusative singular = nominative **minus the final -ς** | every type |
| **Genitive plural is -ων / -ών** | every type, all three genders — one ending to remember |
| The two top rows are identical, and so are the two top neuter rows | that is the point: **A and B differ only in the feminine** |
| Masculine and neuter genitive singular are the same cell | -ού / -ου / -ιού, in every type |
| The feminine plural is **-ες / -ές / -ιές** in all three cases but the genitive | it is the genitive that breaks the pattern, not the accusative |
| ζηλιάρα and ωραία are the same word-shape | the **-ης / -α / -ικο** feminine is type B’s feminine, ending for ending |
| One row never changes at all | μπλε, γκρι, καφέ, ροζ, πορτοκαλί, μωβ — no ending, no agreement |

⚠ **The whole of A2 is the A and B rows — the first two of each gender.** 191 of the 195 adjectives in the A2 wordlist are
type A or type B; γλυκός, ξανθός and Κρητικός are 3 more, and ελαφρύς is the last one. Types C and D
are in the grid so you can recognise them, not so you can drill them.

## A · Type -ος / -η / -ο (καλός — good) ← the main one

✦ also: μεγάλος, μικρός, κακός, ακριβός, φτηνός, ψηλός, όμορφος, δύσκολος, εύκολος

### Singular

| | Masculine | Feminine | Neuter |
|---|---|---|---|
| Nominative | καλ**ός** | καλ**ή** | καλ**ό** |
| Accusative | καλ**ό** | καλ**ή** | καλ**ό** |
| Genitive | καλ**ού** | καλ**ής** | καλ**ού** |
| Vocative | καλ**έ** | καλ**ή** | καλ**ό** |

### Plural

| | Masculine | Feminine | Neuter |
|---|---|---|---|
| Nominative | καλ**οί** | καλ**ές** | καλ**ά** |
| Accusative | καλ**ούς** | καλ**ές** | καλ**ά** |
| Genitive | καλ**ών** | καλ**ών** | καλ**ών** |

## B · Type -ος / -α / -ο (ωραίος — nice)

**When?** Mostly when the stem ends in a **vowel** — ωραίος, νέος, παλιός, κρύος, άδειος, πλούσιος.
⚠ Compare type A: όμορφος→όμορφη, μικρός→μικρή. Not fully predictable — learn each word with its feminine.

| | Masculine singular | Feminine singular | Neuter singular | Masculine plural | Feminine plural | Neuter plural |
|---|---|---|---|---|---|---|
| Nominative | ωραί**ος** | ωραί**α** | ωραί**ο** | ωραί**οι** | ωραί**ες** | ωραί**α** |
| Accusative | ωραί**ο** | ωραί**α** | ωραί**ο** | ωραί**ους** | ωραί**ες** | ωραί**α** |
| Genitive | ωραί**ου** | ωραί**ας** | ωραί**ου** | ωραί**ων** | ωραί**ων** | ωραί**ων** |

The difference from type A is **only the feminine**: -α / -ας instead of -η / -ής.

## C · Type -ύς / -ιά / -ύ (ελαφρύς — light) — **one word at A2**

⚠ **ελαφρύς** is the only adjective of this type in the A2 wordlist. The textbook favourites
(πλατύς, μακρύς, βαθύς, βαρύς, φαρδύς) are **not on it** — recognise the shape, spend your time
elsewhere.

| | Masculine singular | Feminine singular | Neuter singular | Masculine plural | Feminine plural | Neuter plural |
|---|---|---|---|---|---|---|
| Nominative | ελαφρ**ύς** | ελαφρ**ιά** | ελαφρ**ύ** | ελαφρ**ιοί** | ελαφρ**ιές** | ελαφρ**ιά** |
| Accusative | ελαφρ**ύ** | ελαφρ**ιά** | ελαφρ**ύ** | ελαφρ**ιούς** | ελαφρ**ιές** | ελαφρ**ιά** |
| Genitive | ελαφρ**ιού** | ελαφρ**ιάς** | ελαφρ**ιού** | ελαφρ**ιών** | ελαφρ**ιών** | ελαφρ**ιών** |

### The one you will actually meet instead: -ός / -ιά / -ό

**γλυκός** (sweet) → γλυκός / γλυκ**ιά** / γλυκό, plural γλυκοί / γλυκ**ιές** / γλυκά.
Same feminine **-ιά**, but the masculine and neuter stay in type A. Also **ξανθός** (blond,
feminine ξανθή *or* ξανθιά) and **Κρητικός**.

### The one the books skip: -ης / -α / -ικο

**ζηλιάρης** (jealous) → ζηλιάρης / ζηλιάρ**α** / ζηλιάρ**ικο**, plural ζηλιάρ**ηδες** /
ζηλιάρ**ες** / ζηλιάρ**ικα**. The stress never moves off ζηλιά-.

| | Masculine | Feminine | Neuter |
|---|---|---|---|
| Nominative singular | ζηλιάρ**ης** | ζηλιάρ**α** | ζηλιάρ**ικο** |
| Accusative singular | ζηλιάρ**η** | ζηλιάρ**α** | ζηλιάρ**ικο** |
| Genitive singular | ζηλιάρ**η** | ζηλιάρ**ας** | ζηλιάρ**ικου** |
| Nominative plural | ζηλιάρ**ηδες** | ζηλιάρ**ες** | ζηλιάρ**ικα** |
| Accusative plural | ζηλιάρ**ηδες** | ζηλιάρ**ες** | ζηλιάρ**ικα** |
| Genitive plural | ζηλιάρ**ηδων** | ζηλιάρ**ων** | ζηλιάρ**ικων** |

These are the character adjectives — they describe what someone is *like*, so they turn up in
speech far more than in a coursebook. The productive group is **-ιάρης**:

| Greek | English | | Greek | English |
|---|---|---|---|---|
| ζηλιάρης | jealous | | γκρινιάρης | grumpy, whiny |
| τεμπέλης | lazy | | κλαψιάρης | cry-baby |
| πεισματάρης | stubborn | | παραπονιάρης | always complaining |
| φοβητσιάρης | easily frightened | | γλυκούλης | sweet (affectionate) |

⚠ **The masculine looks like a noun and behaves like one.** ζηλιάρης declines exactly like
ο μανάβης; -ιάρης words are in fact used as nouns just as often (είναι ζηλιάρης = he is a
jealous one). The neuter **-ικο** is the giveaway that it is an adjective: a noun in -ης has no
neuter at all.

## D · πολύς (much / many) — irregular but essential ⚠

| | Masculine | Feminine | Neuter |
|---|---|---|---|
| Nominative singular | πολ**ύς** | πολλ**ή** | πολ**ύ** |
| Accusative singular | πολ**ύ** | πολλ**ή** | πολ**ύ** |
| Genitive singular | πολλ**ού** | πολλ**ής** | πολλ**ού** |
| Nominative plural | πολλ**οί** | πολλ**ές** | πολλ**ά** |
| Accusative plural | πολλ**ούς** | πολλ**ές** | πολλ**ά** |
| Genitive plural | πολλ**ών** | πολλ**ών** | πολλ**ών** |

Compare: **πολύ** νερό (much water) · **πολλά** νερά (many waters) · **πολύ** καλός (very good — adverb).

## Position

| Pattern | Example |
|---|---|
| article + adjective + noun (default) | **ο μεγάλος** κήπος |
| predicate (no article on the adjective) | Ο κήπος είναι **μεγάλος**. |
| with a possessive | **το μεγάλο** σπίτι **μου** |
| with a demonstrative | **αυτό το μεγάλο** σπίτι |
