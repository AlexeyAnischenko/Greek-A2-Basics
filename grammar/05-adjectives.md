# 05 · Adjectives (Επίθετα)

**Rule:** the adjective agrees with its noun in **gender + case + number**, and goes **before** the noun.
ο καλός φίλος · τη μεγάλη πόλη · των ωραίων παιδιών

At A2 you need **two** patterns and two footnotes. Counted across the KLIK A2 wordlist:

| Type | A2 adjectives | Verdict |
|---|---|---|
| **A · -ος / -η / -ο** (καλός, όμορφος) | **167** | the pattern — 86% of them |
| **B · -ος / -α / -ο** (ωραίος) | **24** | learn it, it is only the feminine that differs |
| **C · -ύς / -ιά / -ύ** (πλατύς) | **1** — ελαφρύς | one word. Recognise it, do not drill it |
| **-ός / -ιά / -ό** (γλυκός) | **3** | γλυκός, ξανθός, Κρητικός |
| **-ης / -ης / -ες** (διεθνής) | **0** | not an A2 type — not taught on this page |
| **D · πολύς** | grammar word | irregular and unavoidable |

What the grid shows at a glance:

| Pattern | Where it holds |
|---|---|
| The **neuter** singular and plural never change between nominative and accusative | every type — same as the neuter nouns |
| The **genitive plural is -ων / -ών** in all three genders | every type, no exceptions |
| The **feminine singular** is the same in nominative and accusative | every type — only the article moves |
| Masculine accusative singular = nominative **minus the final -ς** | every type |
| A and B differ **only in the feminine** | -η / -ης / -ες vs -α / -ας / -ες |
| Masculine and neuter of γλυκός are plain type A | only its feminine (-ιά / -ιάς / -ιές) is different |
| Vocative = nominative, except masculine singular **-ος → -ε** | καλέ, ωραίε, γλυκέ — ελαφρύς and πολύς have no everyday vocative |
| Invariable colours never agree | μπλε, γκρι, καφέ, ροζ, πορτοκαλί, μωβ — one form for all 18 cells |

⚠ **The whole of A2 is the first two blocks.** 191 of the 195 adjectives in the KLIK A2 wordlist
are type A or type B; γλυκός/ξανθός/Κρητικός are 3 more, and ελαφρύς is the last one. Types C and D
are in the grid so you can recognise them, not so you can drill them.

## A · Type -ος / -η / -ο (καλός — good) ← the main one

✦ also: μεγάλος, μικρός, κακός, ακριβός, φτηνός, ψηλός, όμορφος, δύσκολος, εύκολος

### Singular

| | Masculine | Feminine | Neuter |
|---|---|---|---|
| Nominative | καλ**ός** | καλ**ή** | καλ**ό** |
| Accusative | καλ**ό** | καλ**ή** | καλ**ό** |
| Genitive | καλ**ού** | καλ**ής** | καλ**ού** |
| Vocative | καλ**έ** | καλ**ή** | καλ**ό** |

### Plural

| | Masculine | Feminine | Neuter |

| Genitive | καλ**ών** | καλ**ών** | καλ**ών** |

## B · Type -ος / -α / -ο (ωραίος — nice)

**When?** Mostly when the stem ends in a **vowel** — ωραίος, νέος, παλιός, κρύος, άδειος, πλούσιος.
⚠ Compare type A: όμορφος→όμορφη, μικρός→μικρή. Not fully predictable — learn each word with its feminine.

| | Masculine singular | Feminine singular | Neuter singular | Masculine plural | Feminine plural | Neuter plural |
|---|---|---|---|---|---|---|
| Nominative | ωραί**ος** | ωραί**α** | ωραί**ο** | ωραί**οι** | ωραί**ες** | ωραί**α** |
| Accusative | ωραί**ο** | ωραί**α** | ωραί**ο** | ωραί**ους** | ωραί**ες** | ωραί**α** |
| Genitive | ωραί**ου** | ωραί**ας** | ωραί**ου** | ωραί**ων** | ωραί**ων** | ωραί**ων** |

The difference from type A is **only the feminine**: -α / -ας instead of -η / -ής.

## C · Type -ύς / -ιά / -ύ (ελαφρύς — light) — **one word at A2**

⚠ **ελαφρύς** is the only adjective of this type in the A2 wordlist. The textbook favourites
(πλατύς, μακρύς, βαθύς, βαρύς, φαρδύς) are **not on it** — recognise the shape, spend your time
elsewhere.

| | Masculine singular | Feminine singular | Neuter singular | Masculine plural | Feminine plural | Neuter plural |
|---|---|---|---|---|---|---|
| Nominative | ελαφρ**ύς** | ελαφρ**ιά** | ελαφρ**ύ** | ελαφρ**ιοί** | ελαφρ**ιές** | ελαφρ**ιά** |
| Accusative | ελαφρ**ύ** | ελαφρ**ιά** | ελαφρ**ύ** | ελαφρ**ιούς** | ελαφρ**ιές** | ελαφρ**ιά** |
| Genitive | ελαφρ**ιού** | ελαφρ**ιάς** | ελαφρ**ιού** | ελαφρ**ιών** | ελαφρ**ιών** | ελαφρ**ιών** |

### The one you will actually meet instead: -ός / -ιά / -ό

**γλυκός** (sweet) → γλυκός / γλυκ**ιά** / γλυκό, plural γλυκοί / γλυκ**ιές** / γλυκά.
Same feminine **-ιά**, but the masculine and neuter stay in type A. Also **ξανθός** (blond,
feminine ξανθή *or* ξανθιά) and **Κρητικός**.

## D · πολύς (much / many) — irregular but essential ⚠

| | Masculine | Feminine | Neuter |
|---|---|---|---|
| Nominative singular | πολ**ύς** | πολλ**ή** | πολ**ύ** |
| Accusative singular | πολ**ύ** | πολλ**ή** | πολ**ύ** |
| Genitive singular | πολλ**ού** | πολλ**ής** | πολλ**ού** |
| Nominative plural | πολλ**οί** | πολλ**ές** | πολλ**ά** |
| Accusative plural | πολλ**ούς** | πολλ**ές** | πολλ**ά** |
| Genitive plural | πολλ**ών** | πολλ**ών** | πολλ**ών** |

Compare: **πολύ** νερό (much water) · **πολλά** νερά (many waters) · **πολύ** καλός (very good — adverb).

## Position

| Pattern | Example |
|---|---|
| article + adjective + noun (default) | **ο μεγάλος** κήπος |
| predicate (no article on the adjective) | Ο κήπος είναι **μεγάλος**. |
| with a possessive | **το μεγάλο** σπίτι **μου** |
| with a demonstrative | **αυτό το μεγάλο** σπίτι |
