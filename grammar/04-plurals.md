# 04 · Plurals (Πληθυντικός) — fast lookup

## 1. One-glance conversion table (nominative singular → nominative plural)

| Gender | Sg ending | Pl ending | Example |
|---|---|---|---|
| M | **-ας** | **-ες** | ο άντρας → οι άντρες |
| M | **-ης** | **-ες** | ο μαθητής → οι μαθητές |
| M | **-ος** | **-οι** | ο δρόμος → οι δρόμοι |
| M | **-ές** | **-έδες** | ο καφές → οι καφέδες |
| M | **-ούς** | **-ούδες** | ο παππούς → οι παππούδες |
| F | **-α** | **-ες** | η ώρα → οι ώρες |
| F | **-η** | **-ες** | η νίκη → οι νίκες |
| F | **-η** (abstract) | **-εις** | η πόλη → οι πόλεις |
| F | **-ού** | **-ούδες** | η αλεπού → οι αλεπούδες |
| N | **-ο** | **-α** | το βιβλίο → τα βιβλία |
| N | **-ι** | **-ια** | το παιδί → τα παιδιά |
| N | **-μα** | **-ματα** | το μάθημα → τα μαθήματα |
| N | **-ος** | **-η** | το λάθος → τα λάθη |

## 2. How do I know if -η is F2 (-ες) or F3 (-εις)?

| Type | Marker | Examples |
|---|---|---|
| **-εις** plural | abstract nouns, often from verbs; endings **-ση, -ξη, -ψη, -μη** | η στάση→στάσεις, η τάξη→τάξεις, η σκέψη→σκέψεις, η δύναμη→δυνάμεις, η πόλη→πόλεις, η άσκηση→ασκήσεις |
| **-ες** plural | concrete things & people | η αδερφή→αδερφές, η ζάχαρη→ζάχαρες, η αγάπη→αγάπες, η νίκη→νίκες, η τέχνη→τέχνες |

**Rule of thumb: if it ends in -ση / -ξη / -ψη, the plural is -σεις / -ξεις / -ψεις.**

## 3. Stress-shift plurals (the real trap)

Greek stress may only sit on one of the last three syllables. When the ending grows, the stress **jumps right**.

| Singular | Genitive singular | Nominative plural | Genitive plural |
|---|---|---|---|
| ο **ά**νθρωπος | του ανθρ**ώ**που | οι **ά**νθρωποι | των ανθρ**ώ**πων |
| ο **δά**σκαλος | του δασκ**ά**λου | οι **δά**σκαλοι | των δασκ**ά**λων |
| το **αυ**τοκίνητο | του αυτοκιν**ή**του | τα αυτοκ**ί**νητα | των αυτοκιν**ή**των |
| το **μά**θημα | του μαθ**ή**ματος | τα μαθ**ή**ματα | των μαθη**μά**των |
| το **ό**νομα | του ον**ό**ματος | τα ον**ό**ματα | των ονο**μά**των |
| η **θά**λασσα | της θ**ά**λασσας | οι θ**ά**λασσες | των θαλασσ**ών** |

## 4. A few irregulars you will actually meet

| Singular | Plural |
|---|---|
| το φως | τα φώτα |
| το βράδυ | τα βράδια |
| ο πατέρας | οι πατέρες |
| η μητέρα | οι μητέρες |
| τα Χριστούγεννα, τα γενέθλια, τα λεφτά | plural only — no singular |

## 5. Countable vs. mass

| Concept | Greek |
|---|---|
| some (countable) | **μερικά** βιβλία, **κάποιοι** άνθρωποι |
| some (mass) | **λίγο** νερό, **λίγη** ζάχαρη |
| a lot of | **πολλά** βιβλία / **πολύ** νερό |
| how many? | **Πόσα** βιβλία; **Πόσοι** άνθρωποι; |
| how much? | **Πόσο** νερό; **Πόση** ζάχαρη; |
