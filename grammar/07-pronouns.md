# 07 · Pronouns (Αντωνυμίες)

## 1. Personal pronouns — master grid

| Person | **Nominative** (subject) | **Accusative strong** (emphatic / after preposition) | **Accusative weak** (before verb) | **Genitive weak** (= possessive) |
|---|---|---|---|---|
| 1st singular | εγώ | εμένα | **με** | **μου** |
| 2nd singular | εσύ | εσένα | **σε** | **σου** |
| 3rd singular Masculine | αυτός | αυτόν | **τον** | **του** |
| 3rd singular Feminine | αυτή | αυτήν | **την** | **της** |
| 3rd singular Neuter | αυτό | αυτό | **το** | **του** |
| 1st plural | εμείς | εμάς | **μας** | **μας** |
| 2nd plural | εσείς | εσάς | **σας** | **σας** |
| 3rd plural Masculine | αυτοί | αυτούς | **τους** | **τους** |
| 3rd plural Feminine | αυτές | αυτές | **τις** | **τους** |
| 3rd plural Neuter | αυτά | αυτά | **τα** | **τους** |

**Subject pronouns are normally omitted** — the verb ending already shows the person.
Use them only for emphasis or contrast: Εγώ πάω, εσύ μένεις.

## 2. Weak pronoun placement — the number one A2 error

| Situation | Position | Example |
|---|---|---|
| Normal verb | **before** the verb | **Τον** βλέπω. — I see him. |
| With θα / να / δεν / μη | after the particle, before the verb | Θα **σε** δω. Δεν **το** ξέρω. Να **μου** πεις. |
| **Imperative (positive)** | **after** the verb ⚠ | Δώσε **μου** το! Πες **μου**! |
| Imperative (negative) | before (normal) | Μη **μου** το δίνεις! |
| Two objects | **genitive then accusative** | **Μου το** έδωσε. — He gave it to me. |

**Order when two weak pronouns meet: μου το, σου το, του το, μας τα, σας τις** — genitive first.

## 3. Possessive — the weak genitive, placed AFTER the noun

| English | Greek |
|---|---|
| my house | το σπίτι **μου** |
| your book | το βιβλίο **σου** |
| his / her / its car | το αυτοκίνητο **του** / **της** / **του** |
| our friends | οι φίλοι **μας** |
| your (plural) children | τα παιδιά **σας** |
| their mother | η μητέρα **τους** |

⚠ The article stays: **το** σπίτι μου (not ~~σπίτι μου~~).
⚠ With an adjective: **το μεγάλο σπίτι μου**.

### Emphatic possessive — δικός μου

| | Masculine | Feminine | Neuter |
|---|---|---|---|
| Singular | ο δικός μου | η δική μου | το δικό μου |
| Plural | οι δικοί μου | οι δικές μου | τα δικά μου |

Αυτό είναι **δικό μου**. = This is mine. · Το **δικό μου** σπίτι = MY house.

## 4. Demonstratives — αυτός / εκείνος

| | this (near) | that (far) |
|---|---|---|
| Masculine singular | αυτ**ός** | εκείν**ος** |
| Feminine singular | αυτ**ή** | εκείν**η** |
| Neuter singular | αυτ**ό** | εκείν**ο** |
| Masculine plural | αυτ**οί** | εκείν**οι** |
| Feminine plural | αυτ**ές** | εκείν**ες** |
| Neuter plural | αυτ**ά** | εκείν**α** |

⚠ **Double article rule:** when a demonstrative modifies a noun, the noun **keeps its article**:
**αυτό το** βιβλίο (this book) · **εκείνη η** γυναίκα (that woman) · **αυτά τα** παιδιά

Same for **όλος**: **όλο το** σπίτι (the whole house), **όλοι οι** άνθρωποι (all the people).

Neuter αυτό / εκείνο on its own = "this / that thing": Τι είναι **αυτό**;

## 5. Interrogatives (question words)

| Greek | English | Declines? |
|---|---|---|
| **ποιος / ποια / ποιο** | who? which? | ✔ → ποιον, ποιας, ποιους… |
| **τι** | what? | ✘ |
| **πού** | where? | ✘ |
| **πότε** | when? | ✘ |
| **πώς** | how? | ✘ |
| **γιατί** | why? | ✘ |
| **πόσος / πόση / πόσο** | how much? | ✔ |
| **πόσοι / πόσες / πόσα** | how many? | ✔ |
| **τίνος** | whose? | ✘ |

Ποιον βλέπεις; (whom) · Τίνος είναι αυτό; (whose is this)

## 6. Relative pronoun — at A2 you need only που

**που** is invariable and covers "who, whom, which, that".

| Greek | English |
|---|---|
| Ο άντρας **που** ήρθε. | The man who came. |
| Το βιβλίο **που** διάβασα. | The book that I read. |
| Η κοπέλα **που** γνώρισα. | The girl I met. |
| Χάρηκα **που** σε είδα. | I was glad to see you. |

⚠ **που** (relative, no accent) vs **πού** (where?, with accent).

## 7. Indefinite pronouns (A2 set)

| Greek | English | Notes |
|---|---|---|
| **κάποιος / κάποια / κάποιο** | someone, some | declines |
| **κάτι** | something | invariable |
| **κανένας / καμία / κανένα** | nobody / anybody | needs **δεν**: Δεν είδα **κανέναν**. |
| **τίποτα** | nothing / anything | Δεν θέλω **τίποτα**. |
| **όλος / όλη / όλο** | all, whole | + article: όλο **το** σπίτι |
| **κάθε** | every | invariable: **κάθε** μέρα |
| **άλλος / άλλη / άλλο** | other, another | |
| **μερικοί / μερικές / μερικά** | some (plural) | |
| **ο ίδιος / η ίδια / το ίδιο** | the same | |
| **μόνος μου / μόνη μου** | by myself, alone | |

⚠ Greek uses **double negation**:
Δεν ξέρω **τίποτα**. Δεν ήρθε **κανένας**. Δεν πάω **πουθενά**. Δεν το κάνω **ποτέ**.
