# 00 · Alphabet & Sounds

## The 24 letters

| Upper | Lower | Name | Sound |
|---|---|---|---|
| Α | α | άλφα | a (as in *father*) |
| Β | β | βήτα | **v** |
| Γ | γ | γάμα | soft g / y before ε, ι (γη = "yi") |
| Δ | δ | δέλτα | **th** as in *this* |
| Ε | ε | έψιλον | e (as in *pet*) |
| Ζ | ζ | ζήτα | z |
| Η | η | ήτα | **i** |
| Θ | θ | θήτα | **th** as in *think* |
| Ι | ι | ιώτα | i |
| Κ | κ | κάπα | k |
| Λ | λ | λάμδα | l |
| Μ | μ | μι | m |
| Ν | ν | νι | n |
| Ξ | ξ | ξι | **ks** |
| Ο | ο | όμικρον | o |
| Π | π | πι | p |
| Ρ | ρ | ρο | r (tapped) |
| Σ | σ / **ς** | σίγμα | s — **ς only at word end** |
| Τ | τ | ταυ | t |
| Υ | υ | ύψιλον | **i** |
| Φ | φ | φι | f |
| Χ | χ | χι | ch (German *ach* / *ich*) |
| Ψ | ψ | ψι | **ps** |
| Ω | ω | ωμέγα | o |

**Five ways to write "i":** ι, η, υ, ει, οι — all identical in sound. Spelling must be memorised.
**Two ways to write "o":** ο, ω. **Two ways to write "e":** ε, αι.

## Digraphs (δίψηφα)

| Written | Sound | Example |
|---|---|---|
| αι | e | και (ke) = and |
| ει, οι, υι | i | είναι, οίκος |
| ου | u | πού (pu) = where |
| αυ | af / av | αυτός (aftós), αύριο (ávrio) |
| ευ | ef / ev | ευχαριστώ (efharistó), Ευρώπη (Evrópi) |
| μπ | b (word-start) / mb (inside) | μπύρα (bíra), λάμπα (lámba) |
| ντ | d (word-start) / nd (inside) | ντομάτα (domáta), πέντε (pénde) |
| γκ / γγ | g / ng | γκολ (gol), αγγλικά (anglika) |
| τσ | ts | τσάι (tsái) |
| τζ | dz | τζάμι (dzámi) |
| γχ | nch | συγχαρητήρια |

## Consonant + vowel traps

| Combo | Sound | Example |
|---|---|---|
| γι, γει, γυ | y- | γιατί (yatí), γεια (ya) |
| χι, χε | soft "hy" | χέρι (héri) |
| σ before μ/β/γ/δ | z | κόσμος (kózmos), Ισραήλ |

## Stress (τόνος) — the only accent mark

| Rule | Detail |
|---|---|
| Every word of 2+ syllables | has **exactly one** written accent: μαμά, τραπέζι |
| One-syllable words | no accent… |
| …**except** | πού (where?), πώς (how?), τί/τι, ή (or), πιό/πιο to disambiguate |
| Stress position | only on one of the **last three** syllables |
| Stress **moves** | άνθρωπος → ανθρώπου; μάθημα → μαθήματα (see Nouns, p. 4) |
| Diaeresis ¨ | splits a digraph: παϊδάκι = pa-i-, not pe- |

## Punctuation differences

| Greek | Means |
|---|---|
| **;** | question mark (not semicolon!) |
| **·** | semicolon (ano teleia) |
| « » | quotation marks |
