# 09c · Imperfect — the ongoing past

The imperfect (Παρατατικός) says something **was going on** or **used to happen**: *έγραφα* —
I was writing, *πήγαινα* — I used to go. It is built on the **present** stem.

## 1. Group A: present stem + -α, -ες, -ε, -αμε, -ατε, -αν

The augment rule is the same as in the aorist: stress on the 3rd syllable from the end, **έ-**
when the word is too short.

| Pronoun | Person | γράφω |
|---|---|---|
| **εγώ** | 1st singular | έγραφ**α** |
| **εσύ** | 2nd singular | έγραφ**ες** |
| **αυτός / αυτή / αυτό** | 3rd singular | έγραφ**ε** |
| **εμείς** | 1st plural | γράφ**αμε** |
| **εσείς** | 2nd plural | γράφ**ατε** |
| **αυτοί / αυτές / αυτά** | 3rd plural | έγραφ**αν** / γράφ**ανε** |

⚠ The only difference from the aorist is the **stem**: έγρα**φ**α (imperfect) vs έγρα**ψ**α (aorist).

## 2. Groups B1 / B2: insert **-ούσ-**

| Pronoun | Person | αγαπάω | μπορώ |
|---|---|---|---|
| **εγώ** | 1st singular | αγαπ**ούσα** | μπορ**ούσα** |
| **εσύ** | 2nd singular | αγαπ**ούσες** | μπορ**ούσες** |
| **αυτός / αυτή / αυτό** | 3rd singular | αγαπ**ούσε** | μπορ**ούσε** |
| **εμείς** | 1st plural | αγαπ**ούσαμε** | μπορ**ούσαμε** |
| **εσείς** | 2nd plural | αγαπ**ούσατε** | μπορ**ούσατε** |
| **αυτοί / αυτές / αυτά** | 3rd plural | αγαπ**ούσαν** | μπορ**ούσαν** |

✦ Never an έ- here: -ούσα already gives enough syllables. Many group-A verbs also allow -ούσα.

## 3. Passive / -μαι verbs: **-όμουν**

| Pronoun | Person | έρχομαι | κοιμάμαι |
|---|---|---|---|
| **εγώ** | 1st singular | ερχ**όμουν** | κοιμ**όμουν** |
| **εσύ** | 2nd singular | ερχ**όσουν** | κοιμ**όσουν** |
| **αυτός / αυτή / αυτό** | 3rd singular | ερχ**όταν** | κοιμ**όταν** |
| **εμείς** | 1st plural | ερχ**όμασταν** | κοιμ**όμασταν** |
| **εσείς** | 2nd plural | ερχ**όσασταν** | κοιμ**όσασταν** |
| **αυτοί / αυτές / αυτά** | 3rd plural | έρχ**ονταν** | κοιμ**όνταν** |

## 4. ⚠ Irregular imperfects to memorise

▦ **All four tenses, all six persons** — these 9 plus the 11 next most common irregular verbs:
[20 core irregular verbs](https://alexeyanischenko.github.io/Greek-A2-Basics/core-verbs-grid.html).

| Verb | Imperfect |
|---|---|
| **είμαι** | ήμουν, ήσουν, ήταν, ήμασταν, ήσασταν, ήταν |
| **έχω** | είχα, είχες, είχε, είχαμε, είχατε, είχαν |
| **πάω** | πήγαινα |
| **λέω** | έλεγα |
| **τρώω** | έτρωγα |
| **ξέρω** | ήξερα (⚠ no aorist exists) |
| **θέλω** | ήθελα |
| **πίνω** | έπινα |
| **ακούω** | άκουγα |

**είμαι** and **έχω** have no aorist at all — ήμουν and είχα are their only past, for both
"was" and "was being".
